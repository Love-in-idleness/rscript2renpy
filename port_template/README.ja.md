# 共通 RScript 移植テンプレート

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md) | [日本語](README.ja.md)

[プロジェクトの説明](../README.ja.md) · [新ゲーム移植](../docs/NEW_GAME_PORTING.ja.md)

新規アダプター向けに共通コンパイル、工程生成、GUI を提供します。すべての RScript ゲームを無調整で変換するツールではありません。

## 入力と出力

LiarsoftTool で次を準備します。

- 現形式の `scr/*.tsc`。
- PNG、WebP、JPG、BMP、BMP 形式の MSK。
- 再生可能な OGG または通常 PCM WAV。
- 元 MPG と画像の `.meta.xml`。

CodeX BMP の反転 Alpha は LiarsoftTool が正規化します。本プロジェクトは BMP/MSK を PNG へ変換せずコピーします。出力はシナリオ `game/scr/`、ランタイム・GUI `game/engine/`、言語 `game/tl/<言語>/`。メディアは元ディレクトリ名を保持します。

原版と言語パッケージは共通の選択規則を使い、拡張子の大文字・小文字を区別しません。同じディレクトリの同名 WAV より OGG を優先します。
原文と言語パッチのラベルは重複できず、パッチのパスには実在するディレクトリを指定します。

## 新規アダプター

1. `<ゲーム>/` を作り、共通ランタイムやテンプレートを複製しません。
2. 本作の方言と入力条件を確認し、共通 TSC コンパイラーを使います。
3. `assemble_port` で組み立て、差分は本作の `game/*.rpy` へ置きます。
4. 入力・出力ディレクトリと `--help` を持つコマンドを提供します。
5. ゲーム README に対応版、資源準備、生成、パッチ、制限を書きます。

上書き前に手動変更を確認してください。生成物だけを修正しないでください。

## 共通機能

| 機能 | 内容 |
| --- | --- |
| 文字 | 台詞、追加、文字オブジェクト、制御符、ルビ、折返し |
| 設定 | 字体、サイズ、行字数、行間、言語、システム進捗バックアップ |
| 原画像 UI | 設定、選択肢、制御バー、セーブ・ロード |
| 音声 | BGM、SE、ボイス、再生し直し、自動進行 |
| 言語パッケージ | 翻訳、字幕挿入、作品別の全シーン置換 |
| Android | タッチ操作、スクリーンショット、アイコン、起動説明 |

UI は `.meta.xml` を優先します。命名やボタン動作の差は適応が必要です。名前から役割を識別し、本作のスクリプト・EXE で動作、状態、有効条件を確認します。セーブ枠は章画像と `saveconf` を使えます。

## UI リソースの役割

文字メニューと Android のタッチ操作は、原文のラベルを含めて `zh`、`ru`、`jp` に応じて
中国語・ロシア語・日本語で表示します。それ以外のラベルは英語です。ゲーム画像内の文字は言語パックで提供します。

実装前に素材を確認し、UI をシナリオ画像と取り違えたり、コピーだけして機能を忘れたりしないでください。共通チェックリストであり、異なる命名・欠けたディレクトリは本作で確認します。

| パス | 役割 |
| --- | --- |
| `grps/dt*` | セーブ用画像 |
| `grps/nonbl/` | メニューページ送りの数字 |
| `grps/compane/` | プレイ中の制御バー。ファイル名が機能を示す |
| `grps/confscrn/` | 右クリックメニュー |
| `grps/savescrn/` | セーブ・ロード画面 |
| 各 `.meta.xml` | 画像位置と画布。元の寸法も保持する |

原タイトルメニューを保持し、「環境設定」から既存 Text Settings（`rscript_title_preferences`）を開きます。タイトル全体をテキストメニューに置き換えません。ゲーム内バー、右クリック、セーブ・ロードは原素材を使います。

座標はスクリーンショットから推測せず、すべて中央揃えにせず、`.meta.xml` に従います。`dt*` は通常背景・立ち絵ではなく、`nonbl` はシナリオ文字ではありません。セーブ枠は完全な部品として扱い、`saveconf` のプレビュー、数字、日付、アイコン、選択マスクを確認します。一枚の FileScreenshot で全体を代用しません。選択済み・未選択・ホバーを区別し、各ボタンを正しい動作に接続します。

既定の起動動画は `0002.mpg → 0001.mpg`、起動ごとに一度です。作品別に `rscript_boot_movies` を指定できます。

## 作品差分

入口と分岐、レジスター、画像位置・層、音声番号、文字、メニュー、セーブ、ロールバック、persistent、鑑賞を各作で確認します。再利用できない動作は本作 EXE・スクリプト・実表示で確かめます。未実装を明記し、シナリオ命令を黙って破棄しません。

| `port_resources.py` | メディア、言語資源、項目 |

| `../runtime/` | RScript ランタイム |
