# 开发参考：公共模板与游戏适配

[返回文档目录](README.zh.md) · [通用模板](../port_template/README.zh.md)

本页说明源码分工。构建已有游戏请直接使用各游戏 README。

## 目录分工

| 位置 | 职责 |
| --- | --- |
| LiarsoftTool | 归档、GSC/TSC、编码、图像与音频转换 |
| `runtime/` | RScript 指令、寄存器、图层、文字和音频运行时 |
| `port_template/` | 剧本编译、补丁对齐、资源安装和共用界面 |
| 游戏目录 | 方言、版本检查、默认布局与专用行为 |
| 生成工程 | 构建结果，不是公共代码的维护位置 |

通用修复写入公共层，游戏差异保留在适配层。
不要复制运行时长期分叉，也不要对安装后的公共文件做字符串替换。

## 工程生成

生成器读取已准备好的 TSC，先编译场景，再通过 `assemble_port` 安装工程。
资源转换由用户预先使用 LiarsoftTool 完成。

公共安装负责复制媒体、生成配置和清理对应的 `.rpyc`。
输入资源、补丁和输出工程不能重叠。安装中断后处理错误并重新构建。

剧本位于 `game/scr/`，运行时位于 `game/engine/`，
语言包位于 `game/tl/<语言>/`，媒体保留原目录。

## 语言补丁

| 游戏 | 策略 |
| --- | --- |
| Forest | 文本与字幕对齐；5000 使用整场景替换 |
| Khime | 文本与字幕对齐；外传资源独立 |
| Evermaiden、CannonBall、Kagerou | 整场景覆盖 |

补丁不混入原版目录。缺失译文回退原版；剧情结构不同的语言不能假定存档互通。

## 运行时与界面

文本、语音、点击和绘制队列共用实现，各方言通过明确配置选择行为。
不能仅凭 TSC 字节布局推断原引擎的动画、坐标或计时语义。

`grps_layout.py` 读取复合图元数据，`grps_ui.rpy` 负责设置、选项、
存读档和控制条。原生硬编码界面由游戏适配层提供已核实的布局。
文字默认慢速，玩家设置、持久化进度和每款游戏的存档目录独立维护。

PC 与 Android 显示版本由 `build_port.py` 管理；不要为普通更新提高最低安卓要求。
截图、触摸与打包仍需设备验证。

## 开发检查

公共修改先运行 `test_runtime.py`、`test_port_template.py` 与
`test_shared_port.py`，再检查受影响的游戏。
测试命令见 [文档目录](README.zh.md#开发检查)。
SDK 升级后重跑原生文字和界面测试，完整游玩结果另行记录。
