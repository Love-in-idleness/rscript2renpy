# Перенос Khime Kusaritop

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md) | [日本語](README.ja.md)

## Обзор

Генератор создаёт проект Ren'Py 8 из ваших ресурсов «腐り姫» и может подключить
дополнение «帰省 ～jamais vu～». Команды запускаются из корня репозитория.
См. [настройку среды](../docs/SETUP.ru.md).

## Подготовка ресурсов

```bash
liarsofttool -R --unpack-only --gsc-to-tsc -e cp932 /path/to/Khime
```

Сохраните `scr/*.tsc`, каталоги `grp*`, `.meta.xml`, `bgm/voice/wav` и `mov`.
Ogg внутри WAV сначала извлеките. Обычные PCM WAV и исходные MPG можно использовать
напрямую. Патч преобразуйте отдельно с его фактической кодировкой.

## Сборка проекта

```bash
python3 khime/build_khime_rscript.py /path/to/Khime /path/to/renpy/Khime
```

Генератор создаёт выходной каталог. Перед повторной сборкой сохраните ручные
изменения и добавьте `--force`. Для перехода со старого генератора рекомендуется
новый каталог.

## Языковые патчи

```bash
python3 khime/build_khime_rscript.py /path/to/Khime /path/to/renpy/Khime \
    --language jp --language zh=/path/to/Khime.zh
```

`--language jp` задаёт метку оригинала, `--language zh=каталог` добавляет перевод.
Патч повторяет относительные пути ресурсов и содержит только изменённые TSC,
изображения и аудио.

Можно переводить диалоги, добавляемый текст, выборы и текстовые объекты, добавлять
субтитры и команды ожидания/очистки. Обычный патч не должен произвольно менять
сюжетную логику. Отсутствующие сцены берутся из оригинала. Прозрачность CodeX BMP
подготавливает LiarsoftTool, генератор копирует изображения напрямую.

### Необязательное дополнение

```bash
python3 khime/build_khime_rscript.py /path/to/Khime /path/to/renpy/Khime \
    --language jp --language zh=/path/to/Khime.zh \
    --khime-zero /path/to/Khime_zero \
    --khime-zero-language zh=/path/to/Khime_zero.zh
```

Подключается `scr/2001.tsc`, но не отдельный титульный экран дополнения.
Вход появляется в исходном титуле основной игры после выполнения условий
разблокировки. Ресурсы дополнения не заменяют одноимённые изображения основной
игры. Без патча дополнения используется оригинальный текст.

## Использование

Настройки титула управляют шрифтом, размером, шириной строки, интервалом, языком
и системным прогрессом. По умолчанию размер — 29, ширина диалога — 21 знак.
Скорость и звук меняются во внутриигровых настройках. Видео проигрывается только
при запуске приложения, не при возврате к титулу.

Лицензии общего курсора, шрифтов и значков — в [уведомлениях](../THIRD_PARTY_NOTICES.ru.md).

## Проверка и ограничения

```bash
/path/to/renpy-sdk/renpy.sh /path/to/renpy/Khime lint
```

Некоторые эффекты и цифровые элементы пока воспроизведены не полностью.
У BGM дополнения пока нет плавного появления/затухания. Проверьте маршруты,
галерею, субтитры, звук и старые сохранения; Android проверяется отдельно.

Тесты: `tests/test_khime_builder.py`, `tests/test_khime_zero.py`, `tests/test_shared_port.py`.
Анализ движка — в [технических заметках](../docs/README.ru.md#разработка).
