# Общий шаблон порта RScript

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md)

[Главная страница](../README.ru.md) · [Новая игра](../docs/NEW_GAME_PORTING.ru.md)

Здесь находятся общие средства компиляции сценариев, сборки проекта и интерфейса.
Это не универсальный конвертер любой игры RScript одним нажатием.

## Входные и выходные файлы

Подготовьте ресурсы с помощью LiarsoftTool:

- Актуальные `scr/*.tsc`.
- Изображения PNG, WebP, JPG, BMP и маски MSK в формате BMP.
- Воспроизводимые OGG или обычные PCM WAV.
- Исходные видео MPG и файлы геометрии `.meta.xml`.

LiarsoftTool нормализует обратный альфа-канал BMP CodeX. Проект копирует
BMP/MSK напрямую, без дополнительного преобразования в PNG.

Сценарии готового проекта находятся в `game/scr/`, движок и интерфейс —
в `game/engine/`. Медиа сохраняют исходные имена каталогов.
Языковые ресурсы помещаются в `game/tl/<язык>/`.

## Создание адаптера

1. Создайте каталог игры, не копируя отдельную версию `runtime/` или `port_template/`.
2. Проверьте диалект команд и ресурсы; используйте общий компилятор TSC.
3. Соберите проект через `assemble_port`; особенности игры храните в её `game/*.rpy`.
4. Предоставьте команду сборки с каталогами ресурсов и проекта, а также `--help`.
5. Опишите версию игры, подготовку ресурсов, сборку, патчи и ограничения в README игры.

Перед заменой существующего проекта проверьте ручные изменения.
Исправления должны оставаться в исходниках генератора, а не только в готовом проекте.

## Общие возможности

| Возможность | Назначение |
| --- | --- |
| Текст | Диалоги, дополнения, текстовые объекты, управляющие коды, фуригана и перенос |
| Настройки | Шрифт, размер, длина строки, интервалы, язык и резервная копия прогресса |
| Исходный интерфейс | Настройки, варианты ответа, панель управления, сохранение и загрузка |
| Звук | Музыка, эффекты, голоса, повтор и автоматическое продвижение |
| Языковые пакеты | Перевод, добавленные субтитры и замена отдельных сценариев |
| Android | Сенсорная панель, снимки экрана, значки и уведомление при запуске |

## Ресурсы интерфейса

Проверьте эти ресурсы до реализации экранов. Это общий список проверки:
отсутствующие каталоги и другую схему имён сверяйте с файлами конкретной игры.

| Путь | Назначение |
| --- | --- |
| `grps/dt*` | Изображения сохранений |
| `grps/nonbl/` | Цифры для переключения страниц меню |
| `grps/compane/` | Игровая панель управления; имя изображения указывает функцию кнопки |
| `grps/confscrn/` | Игровое меню правой кнопки мыши |
| `grps/savescrn/` | Изображения экрана сохранения и загрузки |
| `.meta.xml` в каталогах | Координаты изображений и раскладка холста; сохраняйте также исходные размеры |

Сохраняйте исходное главное меню. Его кнопка настроек открывает существующий
экран Text Settings (`rscript_title_preferences`), а не заменяет всё главное меню.
Игровая панель, меню правой кнопки и сохранения используют исходные ресурсы.

Читайте `.meta.xml`: не угадывайте координаты по снимку и не центрируйте всё подряд.
`dt*` — не сюжетные фоны или спрайты, `nonbl` — не текст сценария.
Слот сохранения — полный компонент `saveconf`: превью, цифры, дата, значки и маска
выделения. Один снимок экрана не заменяет всю раскладку. Каждой кнопке назначайте
её действие; отдельно проверяйте выбранное состояние, обычное состояние и наведение.
Имена кнопок помогают найти функцию; действия и условия доступности проверяются
по сценарию или EXE данной игры.

По умолчанию при запуске один раз проигрываются `0002.mpg → 0001.mpg`.
Адаптер может изменить последовательность через `rscript_boot_movies`.

## Особенности игры

Для каждой игры проверяйте запуск и переходы, регистры, координаты и слои,
номера звуков, текст, меню, сохранения, откат, постоянный прогресс и галерею.
Неподтверждённое поведение исследуйте по EXE, сценарию и наблюдениям этой игры.
Явно отмечайте неподдерживаемые эффекты; не удаляйте команды сюжета молча.

| --- | --- |

| `tsc_patches.py` | Языковые патчи и выравнивание субтитров |
| `build_port.py` | Сборка проекта и установка ресурсов |
| `port_resources.py` | Медиа, языковые ресурсы и словарь |
| `grps_layout.py` | Геометрия из метаданных изображений |
| `effect_compat.py` | Проверка совместимости эффектов |
| `game/` | Общий интерфейс Ren'Py |
| `../runtime/` | Исполнительная среда RScript |
