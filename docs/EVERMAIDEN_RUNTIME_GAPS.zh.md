# 开发参考：Evermaiden 运行时

[中文](EVERMAIDEN_RUNTIME_GAPS.zh.md) | [English](EVERMAIDEN_RUNTIME_GAPS.en.md) | [Русский](EVERMAIDEN_RUNTIME_GAPS.ru.md) | [日本語](EVERMAIDEN_RUNTIME_GAPS.ja.md)

[返回文档目录](README.zh.md)

说明现代指令的实现、原生依据和待办。
本文供适配开发查阅，样本和地址不代表其他引擎版本。

本记录针对 `modern-36` 输入。原 EXE 只用于只读静态核实，生成工程不依赖 EXE。
地址是用户提供的 `startup_jp.exe` 的 VA，不代表其它版本具有相同地址。

## 实现与原生依据

- 公共生成入口默认保留动态效果、色彩参数，不再把寄存器表达式转换成 0。
  未支持的常量仍在对应位置注释并降级；动态值由运行时执行时检查。
- 绘制队列里的 effect/tone/tonedep 固定指令执行时的寄存器值，不延迟读取。
- `_update` 计时集中在公共 `rscript_update_duration`，Evermaiden 只选择
  `codex-ms` 策略，不再继承 Forest 的百分之一秒调校。`Step=0` 默认取 10；
  溶解每次等待为毫秒，共 `Step+1` 次；点阵替换为 `Step-1` 次；
  遮罩为 `2*Step-1` 次；白/黑过渡每阶段 `Step+1` 次。
  依据 `43b390` → `453010` / `4531d0` / `453940` / `452e60` 的循环。
  例如 `update 1 16 16` 从 2.56 秒改为名义 0.272 秒。
  不模拟原版绘制耗时和 Sleep/GetTickCount 的额外调度开销；
  固定 load/cls 时长及 move 的速度语义仍不是原引擎精确复制。
- `locgrid` 真正写入共享坐标倍率，修复原先只修改局部变量的问题。
- `group` 保存图层所属组；清除、移动支持 0（全部已加载的 1～99 对象）与大于 100
  的分组选层（取除以 100 的余数）。`group 0` 按原引擎保持无操作。
  全部/分组清除不再绕过逐图层动画；白/黑退出先播放变换再隐藏，左右退出使用退出转场。
- 移动效果 5/6：相反方向的半圆弧移动。依据 `413e40` 的分派及
  `4141b3` / `41421b` → `44d3c0` 的半周角与垂直半径运算。
  沿用现有移动时长及残影机制；并非原引擎逐帧调度的精确复制。
- `tboxloc` / `texloc` / `namloc`：脚本定义文本框、正文、姓名区域。
  `cmploc`：控制条的屏幕位置，不再固定贴到文本框右下角。
- `texsize` / `texcolor`：脚本字号、数字色表参与公共正文布局；
  玩家字号设置仍作为相对缩放。数字色表依据 `43b6d0`。
- `texloc` 的宽度限制与用户每行字数共同确定正文常规行宽，悬挂规则不变。
- `waitloc` / `waitlod` / `waitcol`：等待图标的相对位置、素材编号、颜色。
  图标位置为文本框原点加相对坐标，使用对应 `waitNN` 的元数据。
  通用等待动画先装入 `body` / `grow`，再运行持续定位回调；否则 ATL
  会停在回调处，图案始终为空。独立 GL2 对话测试覆盖语言、编号切换及黑底叠加发光。
- `texruby` 的字号及字体槽参与公共注音度量，仍把注音放在现有行距中。
  `46ad7e` → `46a1e8` 确认此前称为“模式”的参数是字体槽，非对齐模式。
  `46afa0` 的水平定位现已实现：短注音按正文跨度均分单元居中，长注音整体
  居中；正文跨行时递归向上取整分配注音字数。`46b125` 从正文字形单元顶部
  减去偏移值，SDK 的 baseline/ascent 在公共层转换，玩家字号和绘制缩放同步参与。
  在 SDK 改写行尾 advance 前保留塑形前进量，不使用墨迹包围盒估算横向跨度。
  不增加行距、不移动正文；仅现代度量端口启用，旧移植仍保持注音不可拆及墨迹定位。
  不复现未使用的原生竖排注音，也不保证替代字体与 GDI 像素完全一致。
- `texmode`：`42ced0` → `4576c0` 设置段落对齐；`456c5a` 的 1 为居中，
  `456ce9` 的 2 为右对齐，其余为左对齐。在脚本正文矩形内对齐，不覆盖 `^m`。
  原生竖排由另一个字段 `1b0` 控制，不混同于这个参数。
- `texpich`：`42d230` 的两参数存到 `17c` / `180`；`457086` / `457062`
  分别按字号加行距、字形前进量加字距布局。度量与最终显示共用，玩家字号等比
  缩放，玩家行距是相对原默认的调整值，普通 Ren'Py 文本与旧移植保持原行为。
- `texfont`：保存字体槽并使用端口映射；`433e22` 把玩家配置字体追加在槽 2，
  Evermaiden 的全部实际调用均为槽 2，映射至菜单所选字体。槽 0/1 原生固定为
  `Inconsolata gt`（`45f6e7` / `45f733`，字符串 `4cd480`），没有捆绑该字体，
  未映射时退回玩家字体并保留生成注释。非零框号样式更新三个辅助框，依据
  `42a410` / `42a460` / `42aad0`。
- `cls 14`：移向画面右下方后消失，不再转换成瞬间清除。
  实际路径为 `43a9a0` → `410660` → `411b10` 的跳表第 14 项 `411f6a`，
  终点取对象初始化时复制的画布尺寸。现与 load/cls 11～14 共用量化余弦路径，
  使用距离/15 作为速度，再由距离/速度计算步数；见[原生显示模式](NATIVE_VISUAL_MODES.zh.md)。

布局指令的静态调用链：`43b600` / `43b690` / `43b270`（框/正文/姓名），
`43a850`（控制条），`43b870`（字号），`43b840` → `42d0d0`（注音），
`43b920` / `43b900` / `43b8d0`（等待图标）。

- `update 100..299` 已实现（2026-10-10），不再降级。`43b390` 按百位选择
  `453a60 / 4537e0`，十位/个位经 `43ba20` 选旧/新画面的九宫格中心。
  `4542c0 / 451b60` 使用 `W*100/(100+level)` 的整数裁切，中心越界时夹到
  屏幕内。百位 1：level 0..600 步长 20，两阶段各 31×5ms，共 0.310 秒；
  百位 2：0..2000 步长 50，各 41×5ms，共 0.410 秒。Step/Wait 不参与。
  共享实现保持这些裁切与帧时序，真实 Ren'Py 隔离 framebuffer 测试通过。
  Windows GDI 的采样/混合细节尚未逐像素对照；游戏视觉仍需人工确认。
- `mode`：`43c3b0` → `412b00` 重建对象并清除原显示；0 操作所有 1～99
  层（包括未加载的层），大于 100 操作对应组。记录模式，保留背景 CG、文件夹、
  分组和深度。Evermaiden 启用此重建行为，完成的旧移植不自动改变行为。
  模式 1/2 的原生像素存储/GDI 后端差异尚未复制。
- `numenable`：`43bd20` → `41c7c0` 启停独立数字层，复用公共数字层状态，
  队列参数按调用时快照。实际 Evermaiden 仅使用模式 0。
- 动态选择分页：`409750` 在可见答案不超过 5 个时全部显示；从 6 个起每页
  最多 4 个答案加翻页按钮，`4090a1` 翻到下一页，末页循环至首页。
  先按寄存器条件筛选再分页；`dynnext` 指定按钮文字，未设置时使用原生
  `4c902c` 的“次へ”。`43d559` 的 100 条答案上限及 `dynsel` 的清空／追加保留。
  `4080f0` 的第二操作数选择 `sel_qNN`／`sel_aNN` 原图皮肤，交由公共元数据布局；
  退出及异常清除临时皮肤，不影响普通选项。
- 动态选择的无 `selmap` 排布：`408974..408afe` 按皮肤画布尺寸计算总高，
  每个答案前加 5px，顶边为 `max(0, H*80//100-total)//2`；答案各自水平
  居中，标题在其自身居中位置左移 30px。即使标题为空，仍保留标题对象的高度。
  缺少皮肤时保留公共文本菜单；普通选项及 Forest/Khime 排布不改变。
  当前 Evermaiden 输入没有 `selmapNN`，因此使用这个原生后备路径。
  `43d739..43d762` / `43d81d..43d845` 确认只有 Effect=0（启用效果且未跳过）
  才启动运动；其它效果原地放置。2/3 再调用 `update 1/2 15 0`，名义等待为零，
  不人为加动画时长。实际 `2 0 1` 保持原地显示，不被新运动实现改变。
- `dyndo Effect=0` 无 `selmap` 的运动写入公共模板：模式 0/1 从标题位置展开，
  2/3 上下进出，4/5 左右进出；`40943b..4096b9` 的默认分支也保留。
  进入调用 `44d4c0`，标题退出仍用该曲线，未选答案退出调用 `44d310`；
  选中答案留在原位直到其它对象离开。分别复现量化 cos / sin 缓动。
  原生 `408de0` 的距离除以 10、`408c1f` 的距离除以 5 是**速度参数**；
  由 `44d310/44d4c0` 再以距离除以速度确定步数，不把速度误当时长。
  `44d880` 按 `i/256 * 6.283185308` 生成 Q16 表，`44d070` 逐步查表、
  截断坐标，并在剩余步数为零的下一 tick 放到终点。
  定时器由配置 `4eb058+1b4` 经 `433b99` → `452680` 设置：本 EXE 的
  文件内缺省 WORD 为 42ms；构造缺省 50ms 留在公共层，Evermaiden 覆盖为 42ms。
  移植后不读取／携带 EXE，也不读取原游戏用户配置；实际调度仍由 Ren'Py 完成。
  翻页不重复进入动画；关闭效果或已处于 Skip 时不播放运动；运动期间阻止操作。
  使用同一组元数据控件；动画交互不建立额外 checkpoint，不覆盖菜单的回滚前进数据。
  少于速度除数的极短位移直接落到终点，避免原生零速度分支停在起点；
  当前正常皮肤未发现该边界，若出现此类布局需再次比对。

## 未完成的行为

- `makesave` 在 `43e310` → `433140` 复制 0x996c 字节运行状态及 7000 个
  局部寄存器到内存，没有写文件；不是 `renpy.save()` 的等价命令。
  尚未复制其“保存先前快照而不是当前执行位置”的语义。
  数字图层其它命令尚未逐项核实；其它指令的分组选层亦未逐项核实。
- 原版固定字体槽 0/1 的字形未复现；竖排注音布局尚未复现。
- 外部 `selmap` 坐标解析仍未实现：模式 0 应使用其中的起终点；当前只复现
  文件不存在时的原生后备路径。它与 LWG 图像元数据不是同一种文件。
- 其它未知动态效果仍可能在运行时明确报错，不把取消静态清零等同于全部效果支持。
