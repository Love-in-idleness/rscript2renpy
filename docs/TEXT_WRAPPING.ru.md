# Техническая справка: вёрстка текста

[中文](TEXT_WRAPPING.zh.md) | [English](TEXT_WRAPPING.en.md) | [Русский](TEXT_WRAPPING.ru.md) | [日本語](TEXT_WRAPPING.ja.md)

[Документация](README.ru.md)

Общие правила и точки сопровождения. Шрифт, размер и длина строки меняются игроком в настройках.

## Правила

- Ширина равна полноширинному advance базового шрифта × заданное количество; сам текст использует advance после shaping.
- Все порты используют `runtime/kinsoku.json`: формат и стандартные наборы символов совпадают с рантаймом LiarsoftTool. Старые таблицы в коде удалены.
- Последовательность знаков, запрещённых в начале строки, остаётся в предыдущей; открывающие скобки переносятся вместе. Неделимая группа может выйти за ширину, без потери символов и запрещённых переносов.
- Пропорциональный глиф, начинающийся внутри строки, может выступать за край; ширина определяется после shaping.
- ^n задаёт перенос, повторные переносы объединяются. Цвета/ссылки ширину не занимают.
- Имя раскладывается отдельно; встроенное изображение занимает итоговый размер.
- Добавляемый текст перераскладывается с существующим; настройки обновляют и текстовые объекты.

Forest: диалог 19 ширин, объекты 20. Kagerou использует физическую область: горизонтальный текст
переносится по ширине, вертикальный — по высоте, без произвольного лимита, конфликтующего с пресетами.

## Ruby и вертикаль

`|正文[注音]` помечает группу, `字[注音]` — только соседний символ. Для буквальных скобок используйте ［］.
Ruby появляется одновременно с основой и не тратит отдельное время чтения. Проверенные Evermaiden/Kagerou
используют нативное позиционирование; вертикальная ruby Kagerou справа от основы. Направление не меняет размер.
Тире поворачивается как единица глифа, не рисуется обычной горизонтальной линией.
См. [Kagerou](../kagerou/NATIVE_EVIDENCE.ru.md).

## Граничные примеры

Для ширины двух равных знаков ↵ означает перенос:

| Вход | Результат |
| --- | --- |
| 甲乙 | 甲乙 |
| 甲乙丙 | 甲乙↵丙 |
| 甲乙。！ | 甲乙。！ |
| 甲（「乙 | 甲↵（「乙 |
| 甲（乙 | 甲↵（乙 |
| 甲（ | 甲（ |
| 甲（。 | 甲（。 |

У пропорционального шрифта границы могут отличаться. Большой размер или малый интервал требуют
проверки обрезания и перекрытия ruby.

## Сопровождение

| Файл | Назначение |
| --- | --- |
| runtime/kinsoku.json | Единая таблица, устанавливается в `game/engine/kinsoku.json` |
| runtime/rscript_wrap.py | Запреты переноса и алгоритм строк |
| runtime/00_rscript_wrap.rpy | Метрики Ren'Py и раскладка |
| port_template/game/text_features.rpy | Настройки текста |
| Адаптер игры | Значения, область и диалект |

JSON в UTF-8 содержит целое `version: 1` и строки `no_line_start`, `no_line_end`.
Наборы не пересекаются и содержат только символы BMP, кроме NUL. Ошибочная конфигурация вызывает ошибку, без возврата к старым правилам.
Файл читается через ресурсный API Ren'Py, в том числе в упакованных играх. Явные переносы `^n` сохраняются независимо от запретов.

Используются реальные метрики Ren'Py. После обновления SDK повторяйте нативные тесты.
[Шрифты Forest](FOREST_FONT_ANALYSIS.ru.md).
