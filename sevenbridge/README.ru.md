## Обзор

Адаптер создаёт проект Ren'Py 8 из японских ресурсов SEVEN-BRIDGE и необязательного китайского патча.
Исходное поведение соответствует `SBridge_jp.exe`; языковые патчи предоставляются отдельно.

## Подготовка ресурсов

Настройте окружение по [инструкции](../docs/SETUP.ru.md). Работайте с копией игры.
В LiarsoftTool рекурсивно распакуйте архивы и преобразуйте ресурсы. Сохраните
актуальные `scr/*.tsc`, изображения, `.meta.xml`, OGG и обычные PCM WAV.
Параметры преобразования доступны через `liarsofttool -h`.

Нужны каталоги `scr`, `grpe`, `grpo`, `grpo_bu`, `grpo_ex`, `grps`, `bgm`,
`voice` и `wav`. Вложенные голосовые архивы тоже должны быть распакованы.
Скопируйте исходный каталог `mov` в рабочую копию ресурсов, сохранив
`0002.mpg`, `0003.mpg` и `0004.mpg`. При запуске воспроизводится `0002`,
а `0003/0004` вызываются сценариями.

## Создание проекта

Из корня репозитория выполните:

```bash
python3 sevenbridge/build_sevenbridge_rscript.py /path/to/prepared-sevenbridge /path/to/renpy-sevenbridge
```

Перед повторной сборкой сохраните ручные изменения. `--force` разрешает
заменять отличающиеся сгенерированные файлы.

## Языковые патчи

Скопируйте `scr.xfl` и `grps.xfl` китайского патча в отдельный рабочий каталог, затем
преобразуйте их раздельно через LiarsoftTool. Переведённые сценарии используют **GBK**,
но имена файлов в `grps.xfl` и вложенных архивах LWG по-прежнему имеют кодировку **CP932**:

```bash
liarsofttool --unpack-only -R -e gbk /path/to/patch-copy/scr.xfl
liarsofttool --unpack-only -R -e cp932 /path/to/patch-copy/grps.xfl
```

Не преобразуйте весь каталог патча с GBK: имена с полноширинными цифрами, например `nonbl/１`,
будут декодированы неверно. Японская основа использует CP932.
Сборщик читает преобразованные `scr/*.tsc`, а не EXE, GSC или архивы.

Сохраните изображения `grps` и `.meta.xml` из патча: меню, галерея, таблички имён и интерфейс
правой кнопки будут использовать ресурсы выбранного языка. Полная японская версия остаётся
основой ресурсов; неизменённые файлы не нужно дублировать в патче.

```bash
python3 sevenbridge/build_sevenbridge_rscript.py /path/to/prepared-sevenbridge /path/to/renpy-sevenbridge \
    --language jp --language zh=/path/to/patch-copy
```

`--language jp` задаёт подпись исходного языка; `zh=...` добавляет китайский патч для выбора в Text Settings.
Патчи сопоставляются с исходными командами: заменяют текст и могут добавлять субтитры.
Ход сюжета задаёт японский сценарий; отсутствующий перевод остаётся японским.
При смене языка текущая реплика обновляется без перехода к следующей.

## Использование

Главное меню сохраняется; его кнопка настроек открывает настройки текста.
В меню правой кнопки ссылки на настройки текста нет.
Игровая панель, меню правой кнопки и сохранения
используют исходные изображения с раскладкой из `.meta.xml`. Назначение каталогов
описано в [общей инструкции](../port_template/README.ru.md#ресурсы-интерфейса).
Шрифт, размер и перенос строк меняются в общих настройках
текста. Прогресс и открытые материалы галереи сохраняются отдельно в Ren'Py;
исходные сохранения игра не читает и не перезаписывает.

## Проверки и ограничения

Запустите Ren'Py lint по [основной инструкции](../README.ru.md), затем проверьте
изображения, звук и сюжетные маршруты. Без файлов `mov` соответствующие видео
недоступны. Полное прохождение и устройства Android ещё требуют проверки.
Версия EXE и результаты анализа описаны в [технической справке](NATIVE_EVIDENCE.ru.md).
