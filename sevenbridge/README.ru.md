## Обзор

Адаптер создаёт проект Ren'Py 8 из японских ресурсов SEVEN-BRIDGE.
Поведение проверяется по `SBridge_jp.exe`. Китайский патч пока не поддерживается.

## Подготовка ресурсов

Настройте окружение по [инструкции](../docs/SETUP.md). Работайте с копией игры.
В LiarsoftTool рекурсивно распакуйте архивы и преобразуйте ресурсы. Сохраните
актуальные `scr/*.tsc`, изображения, `.meta.xml`, OGG и обычные PCM WAV.
Параметры преобразования доступны через `liarsofttool -h`.

Нужны каталоги `scr`, `grpe`, `grpo`, `grpo_bu`, `grpo_ex`, `grps`, `bgm`,
`voice` и `wav`. Вложенные голосовые архивы тоже должны быть распакованы.
Скопируйте исходный каталог `mov` в рабочую копию ресурсов, сохранив
`0002.mpg`, `0003.mpg` и `0004.mpg`. При запуске воспроизводится `0002`,
а `0003/0004` вызываются сценариями.

## Создание проекта

Из корня репозитория выполните:

```bash
python3 sevenbridge/build_sevenbridge_rscript.py /path/to/prepared-sevenbridge /path/to/renpy-sevenbridge
```

Перед повторной сборкой сохраните ручные изменения. `--force` разрешает
заменять отличающиеся сгенерированные файлы.

## Языковые патчи

Пока поддерживаются только японские сценарии.

## Использование

Главное меню сохраняется; его кнопка настроек открывает Text Settings.
Игровая панель, меню правой кнопки и сохранения
используют исходные изображения с раскладкой из `.meta.xml`. Назначение каталогов
описано в [общей инструкции](../port_template/README.ru.md#ресурсы-интерфейса).
Шрифт, размер и перенос строк меняются в общих настройках
текста. Прогресс и открытые материалы галереи сохраняются отдельно в Ren'Py;
исходные сохранения игра не читает и не перезаписывает.

## Проверки и ограничения

Запустите Ren'Py lint по [основной инструкции](../README.zh.md), затем проверьте
изображения, звук и сюжетные маршруты. Без файлов `mov` соответствующие видео
недоступны. Полное прохождение и устройства Android ещё требуют проверки.
Версия EXE и результаты анализа описаны в [технической справке](NATIVE_EVIDENCE.ru.md).
