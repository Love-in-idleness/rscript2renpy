## 中文补丁 EXE 对照

对照样本为 `SBridge.gbk.exe`，SHA-256：

```text
ca0b635abe9861652182df0ed2ccc6854b580b1c8b41aa8ccf4368390944b74d
```

两个 EXE 均为 462848 字节，`.rdata`、`.data` 与 `.rsrc` 完全相同。
全部差异限于 `.text` 的 110 字节：11 处字体字符集参数由 `0x80`
（日文）改为 `0x86`（简体中文），其余 99 字节修改禁则字符常量。
例如 `0x448290` 的 `CreateFontA` 保留字号 14、字重 700，
`0x4690b0` 的字体名仍为 `ＭＳ ゴシック`。

`0x43e450` 的禁则分类器使用 CP936 字节。相对原有公共规则，
行首禁则新增 `：；％·〃々〗℃′″`，行末禁则新增 `〖`。这是原程序的分类；
移植统一使用 [公共 JSON 禁则](../docs/TEXT_WRAPPING.zh.md)，不再逐作合并旧表。
其余代码、内置配置与固定文字数据未变，因此此样本不需要额外的 EXE 文案映射，
也没有调整菜单功能、鉴赏或文字布局的依据。

以上为文件差分和静态反编译结果；未执行汉化 EXE，不能据此确认全部归档文本的编码、
运行时字体效果或其他汉化版本的行为。

## 资源与入口

从原版 `scr.xfl` 导出当前格式的 TSC，不使用来源不明的旧导出。容器为 `modern-36`；参数布局以每份 TSC 的 `rscript18`、`rscript19` 或 `modern` 元数据为准。

`0000` 初始化后跳到 `0001`，标题的开始选项进入 `0100 → 0110 → 2001`。
CG 鉴赏由 `0201–0208` 与 `0210` 控制，场景鉴赏由 `0301/0302/0310`
与 `5001–5013` 控制，音乐鉴赏由 `0400/0401` 控制。
鉴赏界面由脚本接管；原 EXE 中未使用的 `top_me*` 备用标题不作为本适配的菜单。
保留原作标题，“环境设置”使用公共 Text Settings，不替换整个标题菜单。
CG 组末尾继续左键返回缩略图页，移植的查看器
收尾回到 `r[299]` 所记的来源页，不强行改写 `hit` 的寄存器结果。

`APINI` 位于 `0x469740`；`0x41a260` 使用其画面尺寸与资源路径初始化。
画面为 800×600。`0x41ab90` 先尝试外部 `RsInit.cfg`，再尝试 `RsInit.dll`；
上述基准安装均未提供，故使用 EXE 内置配置。

## 指令与状态

| 实现 | 原生依据 |
| --- | --- |
| 指令分派 | `0x41cc40`，低 opcode 与高位 VM 运算分别处理 |
| 三参数 `locmode` | case `0x26 → 0x420220`，对象 0 应用于全部普通对象 |
| `folder 0` | `0x4204e0`，更新对象 1–49 的资源目录 |
| 单通道音效 | cases `0x3e/0x3f/0x40`，分别读取 1/3/1 个表达式 |
| `getflag` | case `0x72 → 0x421670`，读取编号与模式两个表达式 |
| CG 记录 | `0x41fcc0`，总是记录独立进度位；编号小于 1000 才写 `r[9000+编号]` |
| 普通寄存器快照 | `0x41a260/0x41b070` 为 7000 个 16 位普通寄存器保留快照 |

`getflag` 模式为零时读取进度位并把布尔值写入 `r[0]`；非零时标记进度，
保留 `r[0]`。编号按无符号 16 位处理。`0x41b450/0x41b470` 都使用 bank 0，
底层 `0x424110/0x424190` 按位查询或设置。它们与 `gload` 的 CG 记录共用同一表。
移植以 `persistent.seen_cg` 保存这张表，现有进度备份也包含它。

## 文字与媒体

`0x414990` 读取 `tboxNN` 的布局与图像。原 `tbox00` 为 800×130，文本区域起点
`(0,11)`、尺寸 682×119，等待标记位于 `(690,102)`；`gfNNN` 姓名图片宽 146。
这些布局保留在 `.meta.xml` 中，适配将姓名与正文分开绘制。

`0x413f70` 创建正文组件，`0x415050(this,0x80)` 设置其背景透明度。
设置页中亮图为已选状态，`*_f` 为暗图；共用菜单使用该方向。

`0x41b0b0` 将 `r[1]`、`r[2]`、`r[3]` 写入存档头。`0x4037d0` 使用存档中
的编号读取 `dt1_`、`dt2_`，而不是当前游戏进度；这两个前缀位于
`0x469160`、`0x469158`。本作提供的章节条为 `dt2_*`，因此也保存 `r[2]`。
`nonbl` 的 `1–9` 文件名为全角数字，`10` 为半角；其画布和偏移读取 `.meta.xml`，
不能只尝试半角路径或把裁出的数字直接居中。

`0x41b5b0` 将语音编号按 10000 分组：组 0 使用 `voice/%04d.wav`，
其余使用 `voice/<组>/%04d.wav`。转换后读取同名 OGG；PCM WAV 原样保留。
`0x4218d0` 保留重复参数，其中 `999` 表示循环。

原版 `mov` 包含 `0002.mpg`、`0003.mpg`、`0004.mpg`，格式为 MPEG-1 视频与 MP2 音频。启动回调 `0x4238a0` 在 `0x4238eb/0x42390e` 引用 `mov/0002.mpg`、`mov/0001.mpg`，调用 `0x445240`。移植按 `(2, 1)` 播放存在的视频，缺少 `0001` 时跳过。剧本 `0110/0302` 调用视频 3、4，`2004` 调用 2；构建须保留 `mov/*.mpg` 和对应指令。


存档和读档画面。无显示环境时可用 `xvfb-run -a` 包装检查命令。

SDK 检查不是原程序运行对照。字体栅格、全部转场、完整路线、原生 Windows
与 Android 实机效果仍需单独验收。
