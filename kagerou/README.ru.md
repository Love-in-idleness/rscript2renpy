# Перенос KagerouTouryuuki

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md)

## Обзор

Генератор создаёт проект Ren'Py 8 из ваших ресурсов «霞外籠逗留記».
Поддерживается только игра с установленным «ハチポチ特典»; старая версия без
дополнения не поддерживается. Адаптация ещё дорабатывается.
Команды запускаются из корня репозитория. См. [настройку среды](../docs/SETUP.ru.md).

## Подготовка ресурсов

Преобразуйте рабочую копию после установки дополнения:

```bash
liarsofttool -R --unpack-only --gsc-to-tsc -e cp932 /path/to/KagerouTouryuuki
```

Сохраните исходный `kagerou.exe`, `scr/*.tsc`, все каталоги `grp*`, `.meta.xml`,
`bgm/voice/wav` и `mov`. Китайский патч преобразуйте в отдельной копии.

Генератор читает разметку из поддерживаемого EXE, но не выполняет и не копирует его.
Если в рабочей копии EXE отсутствует, укажите `--exe /path/to/kagerou.exe`.

## Сборка проекта

```bash
python3 kagerou/build_kagerou_rscript.py \
    /path/to/KagerouTouryuuki /path/to/renpy/KagerouTouryuuki
```

Выходной каталог может быть создан автоматически. Перед повторной сборкой
сохраните ручные изменения и добавьте `--force`.

## Языковые патчи

```bash
python3 kagerou/build_kagerou_rscript.py \
    /path/to/KagerouTouryuuki /path/to/renpy/KagerouTouryuuki \
    --language jp --language zh=/path/to/KagerouTouryuuki_CHS
```

Патч должен соответствовать версии с дополнением. Он повторяет относительные
пути игры и содержит только изменённые файлы. Сцены заменяются целиком;
отсутствующие переводы берутся из текущего оригинала.

## Использование

По умолчанию текст вертикальный. Панель текста переключает направление,
размер, положение, тень и шрифт. Направление не меняет выбранный размер.
Back и прокрутка вверх выполняют одинаковый откат.

Переключатели речи персонажей находятся на исходной странице настроек.
CG-, сценическая и музыкальная галереи используют сценарии и ресурсы версии
с дополнением. Видео проигрываются только при запуске; отсутствующие пропускаются.

## Проверка и ограничения

```bash
/path/to/renpy-sdk/renpy.sh /path/to/renpy/KagerouTouryuuki lint
```

Разбиение очень длинных абзацев на страницы, некоторые переходы, точный вид
журнала и импорт оригинальных сохранений пока не завершены. Проверьте реальную
вёрстку, речь, галереи, маршруты и Android.

Тесты: `tests/test_kagerou_native.py`, `tests/test_kagerou_builder.py`,
`tests/run_kagerou_port.py`. Основания: [техническая заметка](NATIVE_EVIDENCE.ru.md).
