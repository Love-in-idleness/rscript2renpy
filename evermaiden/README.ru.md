# Перенос Evermaiden

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md) | [日本語](README.ja.md)

## Обзор

Генератор создаёт проект Ren'Py 8 из ваших ресурсов Evermaiden.
Адаптация ещё дорабатывается. Команды запускаются из корня репозитория.
См. [настройку среды](../docs/SETUP.ru.md).

## Подготовка ресурсов

Оригинал и патч преобразуйте в отдельных рабочих копиях:

```bash
liarsofttool -R --unpack-only --gsc-to-tsc -e cp932 /path/to/Evermaiden
liarsofttool -R --unpack-only --gsc-to-tsc -e gbk /path/to/Evermaiden.zh
```

Сохраните `scr/*.tsc`, все каталоги `grp*`, `.meta.xml`, `bgm/voice/wav` и `mov`.
Пример китайского патча предполагает GBK; для другой версии выберите её кодировку.
Обычные PCM WAV и исходные MPG не нужно дополнительно преобразовывать.

## Сборка проекта

```bash
python3 evermaiden/build_evermaiden_rscript.py \
    /path/to/Evermaiden /path/to/renpy/Evermaiden
```

Выходной каталог может быть создан автоматически. Перед повторной сборкой
сохраните ручные изменения и добавьте `--force`. Адаптация использует отдельный
каталог сохранений и не переносит прогресс старого проекта Evermaiden.

## Языковые патчи

```bash
python3 evermaiden/build_evermaiden_rscript.py \
    /path/to/Evermaiden /path/to/renpy/Evermaiden \
    --language jp --language zh=/path/to/Evermaiden.zh
```

`--language jp` задаёт метку оригинала, `--language zh=каталог` добавляет перевод.
Патч повторяет относительные пути игры и содержит только изменённые файлы.

Здесь сцены заменяются целиком, включая ветвления, выборы и добавленные DLC-сцены
патча. Отсутствующие переводы берутся из оригинала. Используйте доверенные патчи;
не переключайте посреди прохождения языки с разной сюжетной структурой.

## Использование

По умолчанию холст — 1280×720, размер текста — 32, строка — 28 полноширинных знаков.
Настройки титула управляют текстом и языком; внутриигровые настройки используют
исходные изображения. При запуске проигрываются `0002.mpg`, затем `0001.mpg`;
возврат к титулу не повторяет видео. Карты выбора, CG- и музыкальная галереи
по-прежнему управляются исходными сценариями.

Лицензии курсора, шрифтов и значка — в [уведомлениях](../THIRD_PARTY_NOTICES.ru.md).

## Проверка и ограничения

```bash
/path/to/renpy-sdk/renpy.sh /path/to/renpy/Evermaiden lint
```

- Некоторые эффекты, позиции вариантов и внешний вид выбора шрифтов отличаются от оригинала.
- В имеющемся образце ресурсов нет `voice/5/2703`, используемого сценой `2320`,
  и `wav/2527`, используемого сценой `4250`. При отсутствии звука сначала проверьте файлы.
- Полные маршруты, управление галереей, совместимость сохранений и Android ещё требуют проверки.

Тесты: `tests/test_modern_port.py`. Реализация и открытые вопросы:
[техническая заметка](../docs/EVERMAIDEN_RUNTIME_GAPS.ru.md).
