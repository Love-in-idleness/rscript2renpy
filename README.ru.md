# rscript2renpy

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md) | [日本語](README.ja.md)

Создание проектов Ren'Py 8 из сценариев TSC и ресурсов игр на CodeX RScript, которыми вы владеете.
Репозиторий содержит совместимую среду исполнения и сборщики отдельных игр, а не универсальный конвертер.

## Начало работы

Нужны Python 3, Pillow, Ren'Py 8 SDK и
[LiarsoftTool](https://github.com/Love-in-idleness/LiarsoftTool) для распаковки и преобразования ресурсов.

1. Установите инструменты по [руководству настройки и первой сборки](docs/SETUP.ru.md).
2. Скопируйте законно приобретённые файлы игры и подготовьте ресурсы и TSC с помощью LiarsoftTool.
3. По руководству нужной игры создайте, проверьте и запустите проект.

Ресурсы и выходной проект должны находиться в разных каталогах. Сборщики читают TSC, не GSC.

Языковые патчи предоставляются отдельно пользователем.
