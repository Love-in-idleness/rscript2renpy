# 新ゲーム移植ガイド

[中文](NEW_GAME_PORTING.zh.md) | [English](NEW_GAME_PORTING.en.md) | [Русский](NEW_GAME_PORTING.ru.md) | [日本語](NEW_GAME_PORTING.ja.md)

[主説明](../README.ja.md) · [環境構築](SETUP.ja.md)

未対応作品の開発者向けです。対応済み作品は各 README で構築でき、AI は不要です。

## 準備するもの

- 作品名、版、更新、特典。
- 正当に入手した原ゲーム・パッチと、その作業コピー。
- 原 EXE、LiarsoftTool、Ren'Py 8 SDK、出力場所。
- 比較できる原画面、音、操作過程。

LiarsoftTool で TSC と資源を準備します。ディレクトリが似ているだけで既存アダプターを流用しません。

## 開発順序

1. 版、入口、方言、資源配置を確認。
2. 起動、タイトル、冒頭を通し、背景・立ち絵・文字・音声・選択を確認。
3. メニュー、保存、回帰、システム進捗、鑑賞。
4. 別ルート、自動テスト、利用者向け説明。
5. 最後に Android パッケージと実機。

共通実装は `runtime/` と `port_template/`、差分は新しい作品ディレクトリへ置きます。不明な動作は本作 EXE・脚本・実表示を根拠にし、他作品から推測しません。

### UI 資源の確認

実装前に[資源ごとの役割](../port_template/README.ja.md#ui-リソースの役割)を記録します。`dt*` は保存画像、`nonbl` はページ数字、`compane` は制御バー、`confscrn` は右クリック、`savescrn` は保存画面です。別命名や欠けた資源は実物で確認します。

`.meta.xml` の画布、座標、寸法を保持して読みます。画像だけコピーし、座標を推測したり全て中央配置したりしません。`saveconf` の数字・日付も確認します。ボタン動作、選択、ホバーを個別に確認し、似た外観を同じ機能へ接続しません。原タイトルを保持し、「環境設定」だけ既存 Text Settings へ接続します。

## コピーして使える AI プロンプト

パスと版を記入して使ってください。

```text
rscript2renpy を使って次の CodeX RScript ゲームを移植してください。

ゲーム名と版: <名称、更新、特典>
適応ディレクトリ: rscript2renpy/<slug>
原ゲーム資源: <読み取り専用パス>
原 EXE: <読み取り専用パス>
変換コピー: <書込可能パス>
言語パッチ: <言語タグ=パス、なければ「なし」>
rscript2renpy リポジトリ: <パス>
LiarsoftTool リポジトリと CLI: <パス>
Ren'Py 8 SDK: <パス>
出力工程: <新規パス>

同じ版のゲームを所有する利用者が README に従って自分で構築できる、
繰り返し実行可能な生成器を作ることが目標です。

まず両リポジトリの AGENTS.md、README、共通テンプレートを読み、
既存変更を確認してください。版、TSC 方言、入口、資源を確認し、
必要な適応機能を整理してください。

条件:
1. 原本は読み取り専用。変換はコピー上で行い、生成器は TSC のみ受け取る。
2. 資源変換の問題は LiarsoftTool で直す。共通能力は公共層、差分は作品側へ。
3. 流用できない動作は本作 EXE、脚本、実動作で確認し、命令や効果を推測しない。
4. 起動・タイトル・冒頭を先に通し、メニュー・保存・進捗・鑑賞を続ける。
5. 見た目の判断が不確かなときは質問する。未実装を明記し、命令を黙って飛ばさない。
6. 素材、生成工程、セーブ、個人パス、鍵をコミットしない。
7. 新動作にテストを追加し、共通変更は既存移植を検査。実プレイ・Android は別途確認。
8. ゲーム README に対応版、環境、準備、構築、言語パッチ、制限を書く。
9. 独立作業は検証後ローカルコミット。指示なく push・公開しない。

資料と既存実装を調べてから開始してください。
```

## 納品確認

生成器は明瞭な `--help` と入力・出力引数を持ち、保守者の個人パスに依存しません。修正をソースに戻し、手動修正した生成工程だけを残しません。

主 README から作品ガイドへリンクします。開発根拠には版、ハッシュ、アドレス、未知項目を記録し、EXE はコミットしません。[共通テスト](README.ja.md#開発時の確認)と lint 後も、ルート・画面・音を原作と比較します。
