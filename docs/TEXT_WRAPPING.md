# 开发参考：文字布局

[返回文档目录](README.zh.md)

说明公共文字布局的规则与维护入口。玩家修改字体、字号和字数请使用游戏设置。

## 布局规则

- 行宽按基础字体的全角字宽与配置字数计算，实际文字按字体塑形后的前进量排版。
- 允许一个悬挂字形，避免标点独占下一行；开括号不能留在行尾。
- `^n` 强制换行，连续断行合并；颜色、链接等控制符不占字宽。
- 姓名牌独立布局，内联图片按最终尺寸占位。
- 追加文本与已有正文一起重新排版，设置改变后文字对象也会刷新。

Forest 对话默认 19 字宽、文字对象 20 字宽。
Kagerou 使用自己的物理文字区域，横排按宽度、竖排按高度换列，
不使用与预设冲突的任意行字数。

## 注音与竖排

`|正文[注音]` 表示一组注音，`字[注音]` 只标注相邻的一个字。
需要显示普通方括号时使用全角 `［］`。
注音随正文同步逐字显示，不单独消耗阅读时间。

已核实的 Evermaiden 和 Kagerou 使用原生注音定位规则；Kagerou
竖排注音位于正文右侧。横竖切换保留所选字号。
破折号在竖排中按字形单元旋转，不能当作普通横线直接绘制。

原生定位依据见 [Kagerou 注音参考](../kagerou/NATIVE_EVIDENCE.md#注音语法与定位)。

## 边界示例

假定行宽为两个等宽字，`↵` 表示换行：

| 输入 | 结果 |
| --- | --- |
| 甲乙 | 甲乙 |
| 甲乙丙 | 甲乙↵丙 |
| 甲乙。！ | 甲乙。↵！ |
| 甲（乙 | 甲↵（乙 |
| 甲（ | 甲（ |
| 甲（。 | 甲（。 |

比例字体的实际断点可能不同。用户选择很大的字号或很小的行距时，
还需检查裁切和注音重叠。

## 维护入口

| 文件 | 职责 |
| --- | --- |
| `runtime/rscript_wrap.py` | 禁则和断行算法 |
| `runtime/00_rscript_wrap.rpy` | Ren'Py 字形度量与布局衔接 |
| `port_template/game/text_features.rpy` | 文字设置 |
| 游戏覆盖层 | 默认值、文字区域和方言配置 |

布局使用 Ren'Py 的实际字形度量；SDK 升级后重跑原生测试。
Forest 字体选择依据见 [字体参考](FOREST_FONT_ANALYSIS.md)。

## 检查

```bash
python3 -B tests/test_text_wrap.py
python3 -B tests/run_native_text_wrap.py /path/to/renpy-sdk
```

对照游戏检查混合中日英文本、注音、内联图片、追加对话和横竖切换。
