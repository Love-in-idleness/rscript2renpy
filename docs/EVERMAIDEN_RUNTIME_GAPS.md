# Evermaiden 公共运行时修复记录

本记录针对 `modern-36` 输入。原 EXE 只用于只读静态核实，生成工程不依赖 EXE。
地址是用户提供的 `startup_jp.exe` 的 VA，不代表其它版本具有相同地址。

## 已修复

- 公共生成入口默认保留动态效果、色彩参数，不再把寄存器表达式转换成 0。
  未支持的常量仍在对应位置注释并降级；动态值由运行时执行时检查。
- 绘制队列里的 effect/tone/tonedep 固定指令执行时的寄存器值，不延迟读取。
- `locgrid` 真正写入共享坐标倍率，修复原先只修改局部变量的问题。
- `group` 保存图层所属组；清除、移动支持 0（全部已加载的 1～99 对象）与大于 100
  的分组选层（取除以 100 的余数）。`group 0` 按原引擎保持无操作。
  全部/分组清除不再绕过逐图层动画；白/黑退出先播放变换再隐藏，左右退出使用退出转场。
- 移动效果 5/6：相反方向的半圆弧移动。依据 `413e40` 的分派及
  `4141b3` / `41421b` → `44d3c0` 的半周角与垂直半径运算。
  沿用现有移动时长及残影机制；并非原引擎逐帧调度的精确复制。
- `tboxloc` / `texloc` / `namloc`：脚本定义文本框、正文、姓名区域。
  `cmploc`：控制条的屏幕位置，不再固定贴到文本框右下角。
- `texsize` / `texcolor`：脚本字号、数字色表参与公共正文布局；
  玩家字号设置仍作为相对缩放。数字色表依据 `43b6d0`。
- `texloc` 的宽度限制与用户每行字数共同确定正文常规行宽，悬挂规则不变。
- `waitloc` / `waitlod` / `waitcol`：等待图标的相对位置、素材编号、颜色。
  图标位置为文本框原点加相对坐标，使用对应 `waitNN` 的元数据。
- `texruby` 的字号参与公共注音度量，仍把注音放在现有行距中。
  模式与偏移参数保留，但不同模式/偏移的原生放置语义尚未复现。
- `cls 14`：移向画面右下方后消失，不再转换成瞬间清除。
  实际路径为 `43a9a0` → `410660` → `411b10` 的跳表第 14 项 `411f6a`，
  终点取对象初始化时复制的画布尺寸。当前沿用公共 0.5 秒动画时间，
  尚未精确复现原版按距离/15 计算帧数的调度。

布局指令的静态调用链：`43b600` / `43b690` / `43b270`（框/正文/姓名），
`43a850`（控制条），`43b870`（字号），`43b840` → `42d0d0`（注音），
`43b920` / `43b900` / `43b8d0`（等待图标）。

## 尚未完成，不能当作“无扁平化”

- `update 116` 不是缺少 `ef116`，也不能简单解释为反向 `ef16`。
  `43b390` 对百位为 1/2 的值分开处理，十位、个位通过 `43ba20`
  转为位置，再进入 `453a60` / `4537e0` 的组合缩放路径。公共转场尚未复现。
- `mode`、`makesave`、数字图层功能尚未补齐；其它指令的分组选层尚未逐项核实。
- `texfont` 的原生字体槽、`texmode` 和 `texpich` 尚未适配。
- `dyndo` 仍使用公共选项界面，而不是原版动态选项的效果/布局；
  `dynnext` 分页目前明确报未实现，不静默丢选项。
- 其它未知动态效果仍可能在运行时明确报错，不把取消静态清零等同于全部效果支持。
