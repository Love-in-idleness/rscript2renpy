# Техническая справка: текстовые команды Khime

[中文](KHIME_TEXT_CONTROLS.zh.md) | [English](KHIME_TEXT_CONTROLS.en.md) | [Русский](KHIME_TEXT_CONTROLS.ru.md) | [日本語](KHIME_TEXT_CONTROLS.ja.md)

[Документация](README.ru.md)

Управление текстом, оформление выборов и ограничения для того же пользовательского KhimeDL_CHS.exe,
что в [анализе эффектов](KHIME_EFFECT_ANALYSIS.ru.md). EXE не распространяется.
Адреса — VA при ImageBase `0x400000`. Парсер `0x441180` проверяет ^ в `0x441263`,
диспетчеризует через байтовую таблицу `0x4415fc` и указатели `0x4415c8`.
Другой путь `0x4416d0` использует `0x441a94/0x441a64`; регистр команд не важен.

## Подтверждённые команды

| Команда | Ветвь EXE | Поведение |
| --- | --- | --- |
| `^fm` / `^fg` | `0x441371`; подтаблица `0x4416a4/0x441698` | Выбор шрифтового слота m/g до следующего переключения |
| `^cr` | `0x441318` | `#B73333` |
| `^cb` | `0x441342` | `#2020FF` |
| `^cs` | `0x441311` | `#79F1F2` |
| `^cp` | `0x441326` | `#F8B1EF` |
| `^cv` | `0x441334` | `#C187F6` |
| `^co` | `0x44133b` | `#FAA25A` |
| `^v[-0-9]+` | `0x4414e4` / `0x441988` | Последовательные ASCII-цифры/минус становятся полноширинными |

Цветовые подтаблицы `0x441660/0x441634`: ^cy/^cw/^ck — #FFDE00/#FFFFFF/#000000.
Khime ^cg в `0x44132d` — #7FDFA5 из конфигурации, не белый при отключённой Wiki Forest.
Если в языке есть Wiki-запись, общий переключатель всё ещё управляет зелёной ссылкой.
^fm/^fg в `0x441b5b` выбирают `0x46e194/0x46d110`; обе GBK-строки патча — 黑体.
Оба слота сопоставлены существующему fonts/simhei.ttf, по m не угадывается Mincho.
Общий парсер читает rscript_text_fonts; неуказанный слот/отсутствующий файл возвращается к GUI-шрифту.
Новых шрифтов и экстрактора нет.

Одна реализация обслуживает _say, _append, _oload и меню. Реализованные команды не удаляются;
неизвестные уплощаются с локальным комментарием. При смене состояния теги шрифта/цвета/стиля
закрываются и открываются заново без пересечений. Имена, встроенные картинки и Wiki Forest не меняются.

## Оформление выбора <NN>

Не команда ^ и не ненужный префикс. Выбор `0x410b70` проверяет < в `0x410bb6`,
вопрос `0x4133a0` — в `0x4133e8`. `0x44b580` разделяет по первому >,
`0x44b5d0` читает десятичный номер. По умолчанию 0; `0x43e3c0` форматирует младшие 16 бит минимум двумя цифрами.
Базы `0x46d45c/0x46d464` — sel_a/sel_q, поэтому <01>正文 использует grps/sel_a01 либо grps/sel_q01.
Текст после > рисуется через `0x410df0/0x4136db → 0x441140`; маркер скрыт, но выбирает оформление.
Координаты текста — из text, варианты используют body и body_f. При ошибке нумерованного ресурса
`0x410ef1/0x41372a` берёт ненумерованный sel_a/sel_q, не другой произвольный номер.
Общий rscript_menu_panel() читает десятичный маркер, выбирает ресурс и вызывает общий текстовый парсер.
Маркер сохраняется в оригинале, переводе и RPY; lowerer Khime больше не удаляет <01>.
Числовые/регистровые картинки Forest сохраняют прежнюю логику: текстовый маркер не скрывает подпись.
Без оформления — обычные текстовые кнопки; ошибочный маркер не удаляется по догадке.

## Распознано, но воспроизведено не полностью

- ^l/^L, `0x441299`: исходный шрифт, цвет, стиль, задержка, геометрия. Полного сброса нет;
  уплощение отмечается комментарием, это не просто перенос.
- ^c0…^c9, `0x441349`: настраиваемая таблица цветов объекта; неизвестные значения не угадываются, пока уплощаются.
- ^sN, `0x4413f4`: масштаб; `0x441b00`: 0/1/2/3 → 0.5/1/1.5/2, иначе N−1.
  Нынешний прирост размера не эквивалентен, Forest этим анализом тайно не менялся.
- ^dN, `0x4413b9`: N=0 без задержки, иначе база + 2*(N−1). Масштаб CPS приблизителен,
  единицы оригинального таймера ещё требуют сравнения.
- ^m, `0x441468`: состояние 1; `0x44215e` сдвигает на половину свободной ширины.
  Общее центрирование есть, но не полностью повторяет оригинальную построчную геометрию.
- ^g/^a, ^b/^i, ^n используют общий код. В диспетчере этого EXE нет ^w,
  что не опровергает ожидание других диалектов.

## Проверка

tests/test_port_template.py проверяет регистр, сохранение команд и комментарии неизвестных.
tests/run_native_text_wrap.py /path/to/renpy-sdk использует настоящий shaping для смены шрифта,
тегов, полноширинных чисел, переносов и центрирования. tests/test_shared_port.py /path/to/renpy-sdk
проверяет общий парсер, зелёный/слоты Khime и Wiki Forest, не трогая сохранения игрока.
Сами субтитры проверяются вручную, например ^fm титры 1110 и реплики с ^cr.
