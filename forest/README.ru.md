# Перенос Forest

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md)

## Обзор

Генератор создаёт проект Ren'Py 8 из ваших ресурсов Forest.
Команды запускаются из корня репозитория. Среда описана в
[руководстве первой сборки](../docs/SETUP.ru.md).

## Подготовка ресурсов

Распакуйте и преобразуйте рабочую копию игры:

```bash
liarsofttool -R --unpack-only --gsc-to-tsc -e cp932 /path/to/Forest
```

Сохраните `scr/*.tsc`, исходные каталоги `grp*`, `.meta.xml`, аудио
`bgm/voice/wav` и видео `mov`. Титульному экрану нужны `grpe/9001`
и `bgm/Track01.ogg`; вступительные видео — `0002.mpg`, `0001.mpg`.
Языковые патчи преобразуйте отдельно, с их фактической кодировкой.

## Сборка проекта

```bash
python3 forest/build_forest_rscript.py /path/to/Forest /path/to/renpy/Forest
```

Генератор может создать выходной каталог. Повторная сборка заменяет созданные
файлы: сохраните ручные изменения. При переходе со старого генератора лучше
использовать новый выходной каталог.

## Языковые патчи

```bash
python3 forest/build_forest_rscript.py /path/to/Forest /path/to/renpy/Forest \
    --language jp --language en=/path/to/Forest.en \
    --language zh=/path/to/Forest.zh
```

- `--language jp` задаёт метку оригинала; без неё отображается `Original`.
- `--language zh=каталог` добавляет переключаемый перевод; параметр можно повторять.
- Патч повторяет относительные пути игры и содержит только изменённые файлы.
- Метки отображаются в меню, но не выбирают кодировку ресурсов.

В обычных сценах можно переводить диалоги, выборы и текстовые объекты, добавлять
субтитры `*font` к озвученным фрагментам и связанные команды ожидания/очистки.
Не меняйте произвольно ветвления и порядок команд.

`5000.tsc` заменяется целиком для каждого языка; во время финала запрещены откат
и меню. Используйте доверенные патчи. Не переключайте посреди игры языки,
сценарная структура которых различается.

### Wiki

В корне патча можно разместить `keywords.json`:

```json
[["Полное предложение", "https://example.com/wiki", "Слово, выделенное ^cg и ^cw"]]
```

Запись должна совпадать с предложением текущего языка. Wiki по умолчанию
выключена и переключается в китайском внутриигровом меню по правой кнопке.
В настройках титульного экрана этого переключателя нет.

## Использование

- Вступительные видео проигрываются один раз при запуске приложения, не при возврате к титулу.
- Настройки титула управляют шрифтом, размером, шириной строки, интервалом и языком,
  а также резервированием, восстановлением и очисткой системного прогресса.
- Размер по умолчанию — 22; диалог — 19 полноширинных знаков на строку,
  текстовые объекты — 20.
- Дополнительные TTF, OTF и TTC можно положить в `game/fonts/` готового проекта.
- Скорость, звук и сохранения доступны в меню по правой кнопке.

Лицензии курсора, значков и шрифтов — в [уведомлениях](../THIRD_PARTY_NOTICES.ru.md).

## Проверка и ограничения

```bash
/path/to/renpy-sdk/renpy.sh /path/to/renpy/Forest lint
```

Проверьте субтитры, речь, выборы изображениями, возврат из галереи и сохранения.
Старые сохранения, переключение языков и Android требуют проверки на вашей версии ресурсов.

Тесты: `tests/test_forest_validation.py`, `tests/test_forest_builder.py`,
`tests/test_shared_port.py`. Общие правила текста: [техническая заметка](../docs/TEXT_WRAPPING.ru.md).
