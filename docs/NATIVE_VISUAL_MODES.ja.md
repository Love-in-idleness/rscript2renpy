## 色彩モード

0 は変更なし、1 は黒、2 は反転、3 は RGB の算術平均によるグレー、14 は変更なしです。
4～13 は次のアルゴリズムと RGB 定数を使い、HSV フィルタではありません。

| モード | アルゴリズム | RGB |
| --- | --- | --- |
| 4 | Tint | `8b4513` |
| 5 | Tint | `483d8b` |
| 6 | Tint | `ff8000` |
| 7 | Night | `181020` |
| 8 | Level | `282040` |
| 9 | Level | `383080` |
| 10 | Level | `802d50` |
| 11 | Night | `904030` |
| 12 | Level | `805030` |
| 13 | Level | `a06040` |

```text
Grade(x,k) = floor(x*(k+1)/128)                  if k < 128
             floor(x+(256-x)*(2*k-255)/256)     otherwise
Tint(C,T) = Grade(T, floor((R+G+B)/3))
m = min(R,G,B)
Night(C,T) = floor(C*(256-m)/256) + floor(Grade(C,T)*(m+1)/256)
```

色変換は alpha を保持します。15 はバイト量子化と区分的な色相変形を伴う HSL Power で、
単なる彩度上昇ではありません。原生 RGB 例：赤→(255,1,1)、緑→(7,255,1)、青→(255,192,1)。

Forest は 1～6、CannonBall と Khime Zero は 1～5 を実装します。
Khime、SevenBridge、Kagerou、Evermaiden の拡張系列ではオブジェクト型を区別します。
Full は 13 まで、Lim はさらに 15 を実装し、14 は変更しません。
Evermaiden のオブジェクトモード 1 は Full です。列挙外の WORD 値は画像を変更せず、
未実装として降格する対象ではありません。共通層は移動、回転、アニメーション消去中も色を保持します。

## 描画とマスク

新版の `draw 3` は各チャンネルに `Grade(destination, mask)` を適用します。
Level を使わず、普通の alpha 描画でもありません。ユーザーの指定により、旧エンジンで
通常描画の別名だった 3 もこの新版の意味に統一し、他の旧別名は保持します。
`draw 4/5` は黒／白 LUT、強度は `WORD(Level)*255//100` です。
Kagerou の既存の名前付き `dim256` は換算済みのバイト強度を受け取り、再換算しません。
`effect` の 1 以外は GIMP Color-to-Alpha 近似から Grade へ変更し、1 は背景反転のままです。

Grade は GPU の二段描画で、背景のチャンネルを縮尺してからハイライトを加えます。
各段の丸めで最大二階調の差を許容し、GDI の境界画素と完全一致するとは主張しません。
被覆率、深度、通常のラスタ結合を保ち、文字はラスタ結合へ含めません。

## 対角移動と縦縞ワイプ

`load/cls 11～14` は量子化した余弦で左上、右上、左下、右下から入り、または退出します。
角座標は `(-width,-height)`、`(canvasWidth,-height)`、`(-width,canvasHeight)`、
`(canvasWidth,canvasHeight)`。通常位置から locmode の画像アンカーを差し引きます。

原生 `44d4c0` の第三引数はフレーム数ではなく速度です。
`speed=(distance & 65535)//15` の後に `steps=distance//speed` を計算します。
動的選択と同じ Q16 余弦表を使い、最初の tick で起点を保ち、最後に終点を設定します。
グループは同時に開始し、各待ち時間の合計ではなく最長値を共有します。

`load/cls 18` は `x % 16 > level//16` の縦縞ワイプです。
17 の既存 alpha 経路は行と斜線の組合せで、18 と同じ効果ではありません。
17/18 の level は作品ごとの `rscript_dynamic_tick` ごとに 16 変わります。
`update 5～99` はすべて efNN マスク経路で、以前は 5～10 が漏れていました。

根拠：`412e40 / 411b10`（対角と renderer 21）、`44d4c0 / 44d070`（軌跡）、
`443900`（縦縞）、`45a710`（level 初期化）、`43b390`（update 範囲）。

## move 4：作品ごとの動作を維持

実際の移動呼び出しは、各作品とも正弦偏位を加える波状軌跡です。画像コピーの切替ではありません。
以前は Forest の画像切替表 `401280` を移動表と誤認していました。移動入口は `405f00` です。
ユーザーの決定に従い、作品ごとの速度規則を維持し、統一しません。

| 作品 | 移動入口 → 初期化 | 原版の速度規則 |
| --- | --- | --- |
| CannonBall | `404d80 → 4253c0` | tick ごとにリソース座標で固定 30 ピクセル |
| Khime Zero | `405890 → 42e950` | `max(1, WORD(distance//15))` |
| Forest | `405f00 → 436e20` | 同上。スクリプトの Speed は使用しない |
| SevenBridge | `407090 → 43c310` | 同上。スクリプトの Speed は使用しない |
| Khime | `408f30 → 43da10` | `max(1, WORD(distance//(WORD(Speed) or 15)))` |
| Kagerou | `408530 → 4463b0` | 同上 |
| Evermaiden | `413e40 → 44d730` | 同上 |

`steps=WORD(distance//speed)`、移動に垂直な振幅は `(dy,-dx)*3/20` です。
直線部分は Q16 整数演算、正弦位相の増分は `WORD(2*65535//steps)` で、除算はゼロ方向へ切り捨てます。
初期フレームは起点を保ち、原版のステップを消費した後に終点を設定します。
ゼロステップでは移動を開始せず、強制的な瞬間移動にしません。
移植側の拡大前にリソース座標で計算し、アンカー、色、グループの同時開始と最長待機を維持します。
`_move/_movi/_gmove` は共通実装です。104/204 は既存の残像経路を維持しますが、残像の逐フレーム一致は主張しません。

## その場の跳躍と複合消去

7 標本の `move 11/12/13` は X/Y/Speed を無視し、現在位置で縦に跳躍します。
振幅/ステップ数は 40/4、100/10、300/15、位相増分は `0x8800//steps+2` です。
初期フレームは静止し、次 tick から表を参照して `steps+1` tick で原点に戻ります。
残像番号は WORD の後に `%100` を適用し、各移植の tick と座標倍率を維持します。

`cls 30～35` は共通の原生分岐です。30 は 75% 斜め分割後に片側が左下へ、
31 は二片が上下へ、32 は上片が上半円で左へ、35 は上下片が左右へ移動します。
フェードは 30/32 が毎 tick 14/256、31/35 が 16/256 です。
33 は 250 ピクセルの跳躍と初回 tick の 6% からの拡大、34 は同じ跳躍と回転縮小です。
分割・拡縮・回転は Full のみで、Lim/Anim の対応仮想関数は空です。移動とフェードは残ります。
CannonBall は後世の Full/Lim 切替なしに仿射オブジェクトを直接呼び出すため、
既定モード 0 でこれらの効果を無効にしてはいけません。
33/34 の待機は 21/22 tick、非 Full の 34 は跳躍の 21 tick のみです。
グループは最長待機を共有して同時実行し、終了後にレイヤーを消去します。

根拠：`413e40 / 44d570 / 44d070`、`411b10`、`46be30`、`415e80`、`412b00`。

## オブジェクト動作 phase / oaction

共通生成器は初期方言だけでなく全アダプターの TSC `phase` を `_oaction` に変換します。
0 は復元、1/2 は中心を反時計回りに 10/20 刻みで回転し、256 で復元します。
3/4 は 255 から 10/20 ずつ減らして時計回りに回転し、終了時に復元します。
7/8/9 は左下を支点に反時計回りに 64 まで、10/11/12 は右下を支点に時計回りに
192 まで回転します。両組の刻みは 8/12/30。終端姿勢は復元・消去まで保持し、移動で再生し直しません。

ユーザーの最新の決定に従い、全移植の 5/6 は旧版の底辺中央を支点とする型 18 の伸縮に統一します。
位相を毎 tick 10/20 加算し、`u=trunc(sin(phase/256*2π)*50)` から幅/高さの百分率
`100+u / 100-u` を求めます。サイズは Q16 整数切捨て、位相 128 で復元します。
Evermaiden 原 EXE の Full 仮想表 `+0x54` は tick 関数ですが、
その「1 フレーム進める」特殊動作は意図的に使わず、互換切替も残しません。未定義 WORD 番号は何もしません。
効果無効・スキップ時は復元します。ロールバック可能な状態として位置・色・深度を保持し、
消去とオブジェクト再構築時に動作も削除します。
ビットマップ処理は各レイヤーの表示時刻をアニメーションの相対時間に変換します。
単一画像でも結合グループでも、絶対時刻を経過時間と誤認して即座に終了しません。

根拠：Evermaiden `4145c0 / 415e80 / 46c3b0 / 46cd80`；
Forest `4077c0`、Khime `40a980`、Zero `4070f0`、Kagerou `40a800`、CannonBall `4247e0`；
SevenBridge 分岐 `407740`。

`ev_8671b6a05e98ec7f5a2a4fbb7969e1b6dca469b930bcebe324cbe72f8e83b070`,

## 検証と残作業

独立した float32 Power 参照は、限定した原生画素ルーチンと 5102 個の合成 RGBA 標本で一致しました。
原生コードと非公開テスト用バイナリはコミットしません。共通 GL2 検査は色、移動中と終了後、
回転、消去、draw 3/4/5、通常描画への復帰、CG 層との混合を対象とし、完全なプレイ検証ではありません。

引数を受け付けるだけでは効果全体の再現を証明できません。
GL2 検査は跳躍・複合消去の初期・中間・終了フレーム、Full/Lim の差、
動作の支点・実時間の伸縮・単体/結合画像の時計・終端姿勢・移動後の状態保持・消去を対象とします。
分割境界、仿射サンプリング、既存の近似を GDI の逐画素一致とは主張しません。
