# Перенос CannonBall

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md) | [日本語](README.ja.md)

## Обзор

Генератор создаёт проект Ren'Py 8 из ваших ресурсов CannonBall.
Адаптация ещё дорабатывается. Команды запускаются из корня репозитория.
См. [настройку среды](../docs/SETUP.ru.md).

## Подготовка ресурсов

```bash
liarsofttool -R --unpack-only --gsc-to-tsc -e cp932 /path/to/CannonBall
liarsofttool -R --unpack-only --gsc-to-tsc -e gbk /path/to/CannonBall.zh
```

Оригинал и патч преобразуйте отдельно. Сохраните `scr/*.tsc`, все каталоги `grp*`,
`bgm/voice/wav` и имеющиеся видео `mov`. Титулу нужны `grpe/0901`
и `bgm/Track01.wav`. Обычные PCM WAV и исходные MPG используются напрямую;
Ogg внутри WAV сначала извлеките. Китайский пример предполагает GBK;
для другой версии выберите её кодировку.

## Сборка проекта

```bash
python3 cannonball/build_cannonball_rscript.py \
    /path/to/CannonBall /path/to/renpy/CannonBall
```

Выходной каталог может быть создан автоматически. Перед повторной сборкой
сохраните ручные изменения и добавьте `--force`. Обычная сборка не требует EXE игры.

## Языковые патчи

```bash
python3 cannonball/build_cannonball_rscript.py \
    /path/to/CannonBall /path/to/renpy/CannonBall \
    --language jp --language zh=/path/to/CannonBall.zh
```

`--language jp` задаёт метку оригинала, `--language zh=каталог` добавляет перевод.
Патч повторяет относительные пути ресурсов и содержит только изменённые файлы.

Сцены заменяются целиком, с ветвлениями и новыми сценами патча. Текущий китайский
патч отличается по сюжетному потоку; генератор не возвращает его автоматически
к японскому. Используйте доверенные патчи и не переключайте посреди игры языки
с разной структурой сценария.

## Использование

Настройки, сохранения, текстовые выборы и панель управления используют изображения
оригинала. Во время гонок откат и сохранение запрещены; после выхода права
восстанавливаются. Видео `0002.mpg`, `0001.mpg` проигрываются при запуске,
но не при возврате к титулу.

Лицензии курсора, шрифтов и значка — в [уведомлениях](../THIRD_PARTY_NOTICES.ru.md).

## Проверка и ограничения

```bash
/path/to/renpy-sdk/renpy.sh /path/to/renpy/CannonBall lint
```

- Внешний вид истории текста воспроизведён не полностью.
- Некоторые переходы и затухание музыки могут отличаться от оригинала.
- Происхождение потока китайского патча, межъязыковые сохранения, все гонки,
  сражения и сюжетные маршруты требуют отдельной проверки.
- Android требует проверки на устройстве.

Тесты: `tests/test_cannonball_port.py`. Основания и эффекты:
[техническая заметка](NATIVE_EFFECTS.ru.md).
