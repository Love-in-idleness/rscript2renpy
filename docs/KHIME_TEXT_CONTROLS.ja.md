# 開発資料: Khime の文字制御

[中文](KHIME_TEXT_CONTROLS.zh.md) | [English](KHIME_TEXT_CONTROLS.en.md) | [Русский](KHIME_TEXT_CONTROLS.ru.md) | [日本語](KHIME_TEXT_CONTROLS.ja.md)

[文書一覧](README.ja.md)

制御符、選択肢スキン、未再現動作の一覧です。[効果資料](KHIME_EFFECT_ANALYSIS.ja.md)と同じ KhimeDL_CHS.exe を根拠にし、配布しません。以下は ImageBase `0x400000` の VA です。

main parser `0x441180` は `0x441263` で ^ を判定し、byte table `0x4415fc` と pointer table `0x4415c8` で分岐。別経路 `0x4416d0` は `0x441a94/0x441a64`。どちらも大小文字同値です。

## 確認した制御符

| 制御符 | 原分岐 | 動作 |
| --- | --- | --- |
| `^fm / ^fg` | `0x441371`、`0x4416a4/0x441698` | 次の切替まで m / g 字体 slot |
| `^cr` | `0x441318` | #B73333 |
| `^cb` | `0x441342` | #2020FF |
| `^cs` | `0x441311` | #79F1F2 |
| `^cp` | `0x441326` | #F8B1EF |
| `^cv` | `0x441334` | #C187F6 |
| `^co` | `0x44133b` | #FAA25A |
| `^v[-0-9]+` | `0x4414e4 / 0x441988` | 連続 ASCII 数字・負号を全角化 |

色表 `0x441660/0x441634`。既存 ^cy/^cw/^ck は #FFDE00/#FFFFFF/#000000。Khime ^cg は `0x44132d` の #7FDFA5 で、Forest の Wiki-off 白規則を適用しません。ただし現在言語の Wiki 項目がある場合は共通 Wiki スイッチが緑リンクを制御します。

字体は `0x441b5b` から `0x46e194/0x46d110` の二名へ。この中国語 EXE は双方 GBK「黑体」で、既存 fonts/simhei.ttf に対応します。m だから明朝と推測しません。`rscript_text_fonts` を読み、未設定 slot・不足字体は GUI 字体へ戻します。新資源や抽出器は追加しません。

_say、_append、_oload、メニューで共通適用し、生成側は実装済み制御符を削除しません。未知は位置付き注釈で平坦化。字体・色・太字・斜体の切替はタグを閉じて開き直し、交錯させません。Forest の名前・画像・Wiki 色は不変です。

## スキン指定 <NN>

^ 制御符や不要な接頭辞ではありません。選択 `0x410b70 → 0x410bb6`、問い `0x4133a0 → 0x4133e8` は先頭 < を判定し、`0x44b580` で最初の >、`0x44b5d0` で十進番号を読みます。既定0、`0x43e3c0` で低16-bitを少なくとも二桁化。`0x46d45c/0x46d464` は sel_a / sel_q。<01>本文 は grps/sel_a01 または sel_q01 を使います。

本文は `0x410df0/0x4136db → 0x441140`。指定自体は非表示、位置は text、ボタンは body/body_f。ロード失敗 `0x410ef1/0x41372a` は別番号でなく無番号 sel_a/sel_q に戻します。

共通 `rscript_menu_panel()` が十進番号、資源、本文解析を処理します。原文・パッチ・RPY は指定を保持し、Khime lowerer も <01> を削除しません。Forest の数値画像選択は従来どおりで、本文付きスキンのために本文を隠しません。素材なしは通常文字ボタン、不正指定は推測で削除しません。

## 未精密再現

- ^l/^L: `0x441299` は字体・色・装飾・遅延・配置等の初期化。完全リセット未実装、単なる改行とはせず平坦化注釈。
- ^c0…^c9: `0x441349` のオブジェクト色表。未知値を固定色と推測せず平坦化。
- ^sN: `0x4413f4`、`0x441b00` は0/1/2/3→0.5/1/1.5/2、それ以外 N−1。現共通の増分サイズとは異なり、Forest をこの調査で変更しない。
- ^dN: `0x4413b9`、0は遅延なし、他は基準+2*(N−1)。CPS 比例は近似、原時刻単位は未確認。
- ^m: `0x441468` が状態1、`0x44215e` が残幅半分ずらして中央化。Ren'Py 組版との全同値は保証しない。
- ^g/^a、^b/^i、^n は共通実装。此 EXE に ^w 分岐がなくても別方言の wait を否定しない。

## 検証

`tests/test_port_template.py` は大小文字・保持・未知注釈、`tests/run_native_text_wrap.py /path/to/renpy-sdk` は実字体・混合タグ・数字・改行・中央、`tests/test_shared_port.py /path/to/renpy-sdk` は共通 parser、Khime 緑/slot、Forest Wiki を確認します。セーブは操作しません。1110 の ^fm クレジットや ^cr 台詞など、字幕全体は目視確認が必要です。
