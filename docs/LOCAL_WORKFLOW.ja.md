# ローカルパス設定

[中文](LOCAL_WORKFLOW.zh.md) | [English](LOCAL_WORKFLOW.en.md) | [Русский](LOCAL_WORKFLOW.ru.md) | [日本語](LOCAL_WORKFLOW.ja.md)

[文書一覧](README.ja.md)

`local.paths.toml` はローカルのツール、資源、出力場所を記録する任意の設定です。引数の自動指定や言語パッチの自動有効化はしません。

## 設定

ルートの `local.paths.example.toml` を `local.paths.toml` にコピーし、自分の絶対パスを記入します。

| 部分 | 内容 |
| --- | --- |
| `tools` | 両リポジトリ、LiarsoftTool CLI/GUI、ビルド、Ren'Py SDK |
| ゲーム設定 | 変換済み入力、出力工程、基準言語 |
| ゲームの `patches` | 言語タグとパッチ場所 |

不要な欄は空にします。Git 対象外なので個人パスをコミットしないでください。設定ファイルを使わず生成器へ直接パスを渡しても構いません。

## 作業規則

- 原ゲーム・原パッチは読み取り専用とし、コピーで変換します。
- 出力工程は資源の外へ置きます。
- 再構築前に手動変更を保存します。
- `rebuild_local.sh` は保守者向けのローカル補助で、一般利用者の入口ではありません。

二つのリポジトリで同じ設定を共有できます。開発ツールには作業に必要な場所だけを公開してください。
