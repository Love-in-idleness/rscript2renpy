# 開発資料: 文字の組版

[中文](TEXT_WRAPPING.zh.md) | [English](TEXT_WRAPPING.en.md) | [Русский](TEXT_WRAPPING.ru.md) | [日本語](TEXT_WRAPPING.ja.md)

[文書一覧](README.ja.md)

共通組版の規則と保守入口です。字体、サイズ、字数はゲーム設定で変更してください。

## 配置規則

- 行幅は基準字体の全角幅×設定字数。実際の字送りは塑形後の advance を使います。
- 一字のぶら下がりを許し、句読点だけの次行を避けます。開き括弧は行末に残しません。
- `^n` は強制改行で、連続改行はまとめます。色・リンク等は幅を取りません。
- 名前画像は独立配置、インライン画像は最終寸法を使います。
- 追加本文は既存本文と再配置し、設定変更は文字オブジェクトにも反映します。

Forest は台詞 19 字幅、文字オブジェクト 20 字幅。Kagerou は物理文字領域を使い、横は幅、縦は高さで折返すため、preset と競合する任意字数は使いません。

## ルビと縦書き

`|本文[ルビ]` は一組、`字[ルビ]` は直前一字へのルビ。通常の括弧表示には全角 `［］` を使います。ルビは本文と同時に逐字表示し、別の読書時間を消費しません。

確認済み Evermaiden と Kagerou は原生ルビ位置規則を使い、Kagerou の縦ルビは本文右側です。方向変更でも字体サイズは保持します。ダッシュは縦書きで字形単位に回転し、水平線のまま描きません。[原生根拠](../kagerou/NATIVE_EVIDENCE.ja.md#ルビの構文と位置)を参照してください。

## 境界例

等幅二文字の行で、↵ は改行です。

| 入力 | 結果 |
| --- | --- |
| 甲乙 | 甲乙 |
| 甲乙丙 | 甲乙↵丙 |
| 甲乙。！ | 甲乙。↵！ |
| 甲（乙 | 甲↵（乙 |
| 甲（ | 甲（ |
| 甲（。 | 甲（。 |

比例字体では実際の断点が異なります。大サイズや狭い行間は切れ・ルビ重複を確認してください。

## 保守入口

| ファイル | 責任 |
| --- | --- |
| `runtime/rscript_wrap.py` | 禁則・折返し |
| `runtime/00_rscript_wrap.rpy` | Ren'Py 字形計測と接続 |
| `port_template/game/text_features.rpy` | 文字設定 |
| 作品オーバーレイ | 既定値、領域、方言 |

SDK の実字形計測を使うため、更新後は native テストを再実行します。[Forest の字体](FOREST_FONT_ANALYSIS.ja.md)も参照してください。

## 確認

```bash
python3 -B tests/test_text_wrap.py
python3 -B tests/run_native_text_wrap.py /path/to/renpy-sdk
```

日中英混在、ルビ、画像、追加本文、縦横切替を原作と比較します。
