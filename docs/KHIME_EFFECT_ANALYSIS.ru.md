# Техническая справка: эффекты Khime

Параметры объектов, масок и смешивания из пользовательского KhimeDL_CHS.exe; EXE не распространяется.
SHA-256 `522bec3e93340ffd3bdb24ba98cfb775f80df9d85460819da840d824ad4822a8`;
PE32, ImageBase `0x400000`, ниже VA именно этого файла.
load `0x422d70 → 0x4218d0 → 0x4064f0` и font `0x422e20 → 0x421a00 → 0x4066f0`
входят в `0x4070b0`; cls `0x423080 → 0x421b30 → 0x406790` — в `0x407ec0`.
Эффекты общие для текста и изображений: нельзя обнулять все ненулевые _oload.

| Эффект | load / cls | Значение / реализация |
| --- | --- | --- |
| 3 | `0x407218 / 0x407f7a` | Renderer 2, шаг alpha 32; обычное затухание |
| 4 | `0x40724a / 0x407fae` | Renderer 0x12, шаг 32; упорядоченный переход |
| 10 | `0x4073da / 0x4081ed` | Вход снизу / уход вниз; приближённая нативная траектория |
| 15 | `0x40771d / 0x408485` | Renderer 4, шаг 16; RGB к белому с сохранением alpha |
| 19 | `0x4077f9 / 0x40854e` | Renderer 2, шаг 8; вчетверо дольше обычного |

Renderer 4: `0x436c2e → 0x439d60`, смешивает RGB с белым.
Vtable +0x40/+0x44 вызывает `0x407d60` (ret 4); параметр 20 не доказывает масштабирование.
_effect `0x4235a0` выбирает renderer по Mode: mode 1 `0x67 → 0x43b0f0` инвертирует RGB
в нулевой красной области маски; остальные `0x68 → 0x43b1f0` смешивают средне-серую яркость.
Общий shader добавляет инверсию, mode 0 сохраняет прежнее приближение яркости.
Реальные имена вроде ES101.png в верхнем регистре: поиск игнорирует регистр, но сохраняет настоящий путь без копирования/переименования.
Базовые 0.5s effect 3 дают 2s для 19 и 1s для 15. Исходные интервалы кадров,
ускорение и округление пикселей пока приблизительны; статический анализ/lint не доказывают совпадение изображения.
Неизвестные эффекты уплощаются с комментарием; текст effect 0 сохраняет появление Forest.
Проверка: python3 -B tests/test_shared_port.py /path/to/renpy-sdk — настоящие shaders, инверсия/белые пиксели,
очередь и эффекты текста в изолированных проектах. Ручные случаи: 1102 (19), 1110 (текст 4), 7501 (clear 10), 7503 (load 15).
