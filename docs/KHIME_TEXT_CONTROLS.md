# Khime `^` 文本控制符

静态依据为 [特效分析](KHIME_EFFECT_ANALYSIS.md) 中同一份用户持有的
`KhimeDL_CHS.exe`。不分发 EXE；地址均为 ImageBase `0x400000` 下的 VA。

主解析器 `0x441180` 在 `0x441263` 判断 `^`，通过
`0x4415fc` 的字节表和 `0x4415c8` 的指针表分派；
另一解析路径 `0x4416d0` 使用 `0x441a94/0x441a64`。
两个表均接受大小写等价的控制符。

## 本次加入公共运行时的控制符

| 控制符 | 原版分支 | 行为 |
| --- | --- | --- |
| `^fm` / `^fg` | `0x441371`，子表 `0x4416a4/0x441698` | 选择字体槽 m / g，持续到下一次字体切换 |
| `^cr` | `0x441318` | `#B73333` |
| `^cb` | `0x441342` | `#2020FF` |
| `^cs` | `0x441311` | `#79F1F2` |
| `^cp` | `0x441326` | `#F8B1EF` |
| `^cv` | `0x441334` | `#C187F6` |
| `^co` | `0x44133b` | `#FAA25A` |
| `^v[-0-9]+` | `0x4414e4` / `0x441988` | 连续 ASCII 数字、负号转换成全角字形 |

颜色子表为 `0x441660/0x441634`。既有 `^cy/^cw/^ck` 对应
`#FFDE00/#FFFFFF/#000000`；Khime 的 `^cg` 在 `0x44132d` 是
`#7FDFA5`，由游戏配置声明，不套用 Forest 的 Wiki-off 白色策略。
有当前语言 Wiki 词条时，公共 Wiki 开关仍优先控制绿色链接。

`^fm/^fg` 最终在 `0x441b5b` 按状态选择 `0x46e194/0x46d110`
两个字体名；本汉化 EXE 的这两串 GBK 字节均为“黑体”。因此 Khime
覆盖层将两个槽均映射到已有 `fonts/simhei.ttf`，不凭字母 m 推断本 EXE
使用明朝字体。公共解析器读取 `rscript_text_fonts`；未配置槽使用 GUI 字体，
缺失映射字体也回退 GUI 字体。不新增字体资源或提取器。

实现统一作用于 `_say`、`_append`、`_oload` 和菜单文字。
生成兼容检查不再删除上述控制符，未知控制符仍扁平化并在该处注释。
原生字体、颜色、粗斜体标签在状态切换时闭合再重开，避免交叉标签。
Forest 的既有姓名牌、内联图片和 Wiki 配色保持不变。

## 已识别但尚未精确复现的部分

- `^l` / `^L`：`0x441299` 恢复初始字体、颜色、粗斜体、逐字延迟、布局等
  状态。尚未实现完整复位，继续以生成注释记录扁平化，不仅当作换行。
- `^c0`…`^c9`：`0x441349` 从对象的可配置颜色表取值。没有把未知表值
  猜成固定颜色；目前仍扁平化。
- `^sN`：`0x4413f4` 设置字形尺寸倍率；`0x441b00` 中
  0/1/2/3 对应 0.5/1/1.5/2，其他值对应 N−1。
  现有公共运行时的增量字号处理尚不等价，未在本次悄然改动 Forest。
- `^dN`：`0x4413b9` 改变逐字延迟，N=0 为零延迟；非零值为基准延迟
  加 `2*(N−1)`。现有 CPS 比例处理是近似；原版时钟单位尚需对照确认。
- `^m`：`0x441468` 设置布局状态 1；`0x44215e` 以剩余行宽的一半偏移
  实现居中。公共实现已有居中，但原版逐行布局不等于 Ren'Py 的全部排版行为。
- 图像 `^g/^a`、粗斜体 `^b/^i`、断行 `^n` 沿用公共实现。
  此 EXE 的控制分派表没有 `^w`，不能用它否定其他游戏方言的等待语义。

## 验证

`tests/test_port_template.py` 检查大小写、保留已实现控制符及未知控制符注释。
`tests/run_native_text_wrap.py /opt/apps/renpy` 使用真实字体塑形检查
字体切换、混合标签、全角数字、换行和居中标志。
`tests/test_shared_port.py /opt/apps/renpy` 检查两款工程共用解析器、
Khime 绿色/字体槽与 Forest Wiki 行为；不操作玩家存档。
完整字幕画面仍需人工确认，例如 1110 的 `^fm` 制作人员表与含 `^cr` 的对白。
