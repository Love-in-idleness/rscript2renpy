# Техническая справка: runtime Evermaiden

[中文](EVERMAIDEN_RUNTIME_GAPS.zh.md) | [English](EVERMAIDEN_RUNTIME_GAPS.en.md) | [Русский](EVERMAIDEN_RUNTIME_GAPS.ru.md) | [日本語](EVERMAIDEN_RUNTIME_GAPS.ja.md)

[Документация](README.ru.md)

Реализация современных команд, основания и открытые вопросы для modern-36.
EXE используется только для статического чтения, готовому проекту не нужен.
Адреса — VA образца startup_jp.exe, не всех версий.

## Реализация и основания

- Генерация сохраняет динамические эффекты/цвета, не обнуляет регистровые выражения.
  Неподдержанные константы получают комментарий упрощения, динамика проверяется при исполнении.
- Очередь effect/tone/tonedep фиксирует регистры при команде, не читает их позднее.
- _update использует общий rscript_update_duration и стратегию codex-ms, не сотые секунды Forest.
  Step=0→10; dissolve ждёт Step+1 раз, сетка Step−1, маска 2*Step−1,
  белый/чёрный переход Step+1 на фазу, миллисекунды. Основания: 43b390 → 453010 / 4531d0 / 453940 / 452e60.
  update 1 16 16: номинально 0.272s вместо 2.56s. Стоимость рисования и Sleep/GetTickCount не моделируются;
  фиксированное время load/cls и скорость move всё ещё приблизительны.
- locgrid действительно пишет общий множитель координат, не локальную переменную.
- group хранит группу; clear/move поддерживают 0 (загруженные 1–99) и >100 (остаток от деления на 100).
  group 0 остаётся no-op. Общая/групповая очистка сохраняет анимации; белый/чёрный выход сначала преобразует,
  затем скрывает, левый/правый использует выходной переход.
- Move 5/6 — противоположные полукруги: 413e40, 4141b3 / 41421b → 44d3c0, пол-оборота и вертикальный радиус.
  Время/шлейф прежние, не точное расписание кадров.
- tboxloc/texloc/namloc задают области рамки/текста/имени; cmploc отдельно ставит панель,
  не привязывает к нижнему правому углу рамки.
- texsize/texcolor участвуют в геометрии и числовой палитре 43b6d0; размер игрока — относительный масштаб.
  texloc и выбранная длина строки совместно ограничивают ширину, правило висячих знаков сохраняется.
- waitloc/waitlod/waitcol задают относительные координаты, ресурс и цвет. Координаты — начало рамки плюс смещение,
  с метаданными waitNN. Сначала загружаются body/grow, затем постоянный callback положения,
  иначе ATL остаётся с пустой картинкой. GL2-диалог проверяет смену языка/номера и свечение на чёрном.
- texruby задаёт размер/слот в общих метриках внутри прежнего интервала. 46ad7e → 46a1e8 подтверждает слот,
  не выравнивание. 46afa0 распределяет короткую ruby по основе, длинную центрирует целиком,
  при переносе рекурсивно распределяет количество с ceil. 46b125 вычитает смещение из верха основной ячейки;
  общий слой преобразует baseline/ascent SDK, учитывает размер игрока/масштаб.
  Shaped advance сохраняется до перезаписи конца строки SDK; ink bounds не заменяют ширину.
  Интервал не увеличивается, основа не сдвигается. Только современные metric-порты включают это,
  старые сохраняют неразрывную ruby/ink-положение. Неиспользуемая вертикальная ruby и точные GDI-пиксели не повторены.
- texmode: 42ced0 → 4576c0; 456c5a mode 1 — центр, 456ce9 mode 2 — справа, остальные слева,
  в области сценария, без отмены ^m. Вертикаль хранится отдельно в 1b0.
- texpich: 42d230 сохраняет аргументы в 17c/180; 457086 / 457062 использует размер+межстрочный
  и advance+межсимвольный интервалы. Метрики и показ общие, масштаб игрока пропорционален,
  его интервал относителен исходному. Обычный Ren'Py-текст и старые порты не меняются.
- texfont хранит слот/сопоставление. 433e22 добавляет шрифт игрока в слот 2, все реальные вызовы Evermaiden используют 2.
  Слоты 0/1 — Inconsolata gt (45f6e7 / 45f733, строка 4cd480), шрифт не включён.
  Без сопоставления — шрифт игрока и комментарий. Ненулевой номер рамки обновляет три вспомогательные
  рамки: 42a410 / 42a460 / 42aad0.
- cls 14 уходит вправо-вниз и исчезает, не мгновенно: 43a9a0 → 410660 → 411b10,
  элемент 14 в 411f6a; цель — размеры холста, скопированные при создании объекта.
  Теперь общий путь load/cls 11–14 использует квантованный косинус: distance/15 — скорость,
  distance/speed — число шагов. См. [исходные режимы](NATIVE_VISUAL_MODES.ru.md).

Пути геометрии: 43b600 / 43b690 / 43b270 (рамка/текст/имя), 43a850 (панель), 43b870 (размер),
43b840 → 42d0d0 (ruby), 43b920 / 43b900 / 43b8d0 (ожидание).

- update 100..299 использует исходные кадры и обрезку. 43b390 выбирает 453a60 / 4537e0 по сотням,
  десятки/единицы через 43ba20 выбирают центры 3×3 старого/нового экрана.
  4542c0 / 451b60 обрезает целочисленно W*100/(100+level), центр ограничен экраном.
  Сотня 1: 0..600 по 20, две фазы 31×5ms=0.310s; сотня 2: 0..2000 по 50,
  две 41×5ms=0.410s. Step/Wait не участвуют. Реальный изолированный framebuffer Ren'Py проверен;
  выборка/смешивание GDI ещё не сравнены попиксельно, игра требует ручного осмотра.
- mode: 43c3b0 → 412b00 пересоздаёт/очищает объекты; 0 — все 1–99, включая незагруженные;
  >100 — группа. Сохраняются режим, фоновый CG, каталог, группа, глубина. Evermaiden включает это,
  старые готовые порты не меняются автоматически. Нативные mode 1/2 хранения/GDI не повторены.
- numenable: 43bd20 → 41c7c0 включает числовой слой через общее состояние/снимок очереди.
  Реальный Evermaiden использует только 0.
- Динамические выборы: 409750 показывает до пяти ответов целиком; с шести — четыре плюс следующая страница.
  4090a1 листает с возвратом к первой. Сначала фильтруются регистры. dynnext задаёт подпись,
  по умолчанию 4c902c «次へ»; сохраняются предел 100 ответов 43d559 и очистка/добавление dynsel.
  Второй аргумент 4080f0 выбирает sel_qNN/sel_aNN через общие метаданные. Выход/ошибка очищает временное оформление,
  не обычные варианты.
- Без selmap 408974..408afe суммирует высоты холстов, по 5px перед каждым ответом;
  верх=max(0,H*80//100-total)//2. Ответы по центру, заголовок левее своего центра на 30px.
  Пустой заголовок сохраняет высоту. Нет оформления — обычное меню; прочие/Forest/Khime не меняются.
  В текущем Evermaiden нет selmapNN, используется этот fallback. 43d739..43d762 / 43d81d..43d845
  запускает движение только при Effect=0, включённых эффектах и без skip.
  Иначе неподвижно; 2/3 вызывает update 1/2 15 0 без номинального ожидания, искусственная длительность не добавляется.
  Реальный 2 0 1 остаётся неподвижным.
- dyndo Effect=0 без selmap: 0/1 разворачивается от заголовка, 2/3 вертикально, 4/5 горизонтально;
  сохраняется default 40943b..4096b9. Вход/выход заголовка — 44d4c0, выход невыбранных — 44d310,
  выбранный ждёт ухода остальных. Воспроизведено квантованное cos/sin.
  408de0 distance/10 и 408c1f distance/5 — скорость; 44d310/44d4c0 определяет шаги как distance/speed,
  не считает скорость временем. 44d880 строит Q16 по i/256*6.283185308, 44d070 читает таблицу,
  усекает координаты и ставит конечную точку в следующий tick после нуля оставшихся шагов.
  Настройка 4eb058+1b4 через 433b99 → 452680: WORD файла 42ms, конструктор общего слоя 50ms,
  Evermaiden переопределяет на 42ms. Порт не читает/не включает EXE и CFG пользователя; планирует Ren'Py.
  Листание не повторяет вход, выключенные эффекты/skip отключают движение; во время движения управление заблокировано.
  Те же элементы метаданных, без новых checkpoint и перезаписи данных rollback-forward меню.
  Очень короткое расстояние меньше делителя скорости сразу достигает цели вместо нативного зависания на нуле;
  обычные текущие оформления этого не содержат, при появлении нужна новая сверка.

## Не завершено

- makesave 43e310 → 433140 копирует 0x996c байтов состояния и 7000 локальных регистров в память,
  не файл; не эквивалент renpy.save(). Сохранение предшествующего снимка вместо текущего исполнения не реализовано.
  Остальные числовые команды и выбор групп других команд отдельно не проверены.
- Глифы фиксированных слотов 0/1 и вертикальная ruby не воспроизведены.
- Координаты внешнего selmap не читаются: mode 0 должен брать его начальные/конечные точки.
  Реализован только fallback отсутствующего файла; selmap — не метаданные изображений LWG.
- Неизвестные динамические эффекты могут явно завершаться ошибкой. Сохранение выражений не означает поддержку всех эффектов.
