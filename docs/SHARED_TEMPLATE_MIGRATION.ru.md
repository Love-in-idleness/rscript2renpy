## Ответственность

| Место | Задача |
| --- | --- |
| LiarsoftTool | Архивы, GSC/TSC, кодировки, преобразование изображений/аудио |
| runtime/ | Команды, регистры, слои, текст и аудио |
| port_template/ | Компиляция, выравнивание патчей, установка ресурсов, общий UI |
| Адаптер игры | Диалект, версии, геометрия по умолчанию, особое поведение |
| Готовый проект | Результат сборки, не место сопровождения общего кода |

Общее исправляется в общем слое, различия — в адаптере. Не создавайте расходящиеся копии runtime
и не исправляйте установленные общие файлы строковыми подстановками.

## Генерация

Генератор читает подготовленный TSC, компилирует сцены и устанавливает через assemble_port.
Ресурсы заранее преобразует пользователь в LiarsoftTool. Общая установка копирует медиа/конфигурацию
и удаляет соответствующие .rpyc. Входы, патчи и выход не перекрываются.
После прерывания устраните ошибку и пересоберите. Сценарии — game/scr/, runtime — game/engine/,
языки — game/tl/<язык>/; медиа сохраняет исходные каталоги.

Установка защищает замену отдельных файлов, не транзакцию всего проекта. Сбой после очистки языкового каталога может оставить неполный результат: устраните ошибку и повторите сборку. Не запускайте несколько сборщиков для одного выхода одновременно.

## Патчи

| Игра | Стратегия |
| --- | --- |
| Forest | Выравнивание текста/субтитров; полная замена 5000 |
| Khime | Выравнивание текста/субтитров; отдельные ресурсы дополнения |
| Evermaiden, CannonBall, Kagerou | Полная замена сцен |

Не смешивайте патчи с оригиналом. Отсутствующий перевод берётся из оригинала;
сохранения между разными сюжетными структурами не считаются совместимыми.

## Runtime и UI

Текст, речь, клики и очередь рисования общие; поведение выбирает явная конфигурация диалекта.
Структура байтов TSC не доказывает семантику анимации, координат и времени.
grps_layout.py читает метаданные составных изображений; grps_ui.rpy отвечает за настройки,
выборы, сохранения и панель. Для жёстко заданного UI адаптер передаёт проверенную геометрию.
Текст по умолчанию медленный; настройки игрока, постоянный прогресс и каталоги сохранений игр независимы.
Версия PC/Android задаётся build_port.py; обычное обновление не повышает минимум Android.
Снимки, сенсорное управление и упаковка ещё требуют устройств.

## Проверка

Сначала test_runtime.py, test_port_template.py, test_shared_port.py, затем затронутые игры.
Команды: [документация](README.ru.md#проверки-разработчика). После обновления SDK повторяются
нативные проверки текста/UI; полное прохождение отмечается отдельно.
