# 開発資料: Evermaiden ランタイム

[中文](EVERMAIDEN_RUNTIME_GAPS.zh.md) | [English](EVERMAIDEN_RUNTIME_GAPS.en.md) | [Русский](EVERMAIDEN_RUNTIME_GAPS.ru.md) | [日本語](EVERMAIDEN_RUNTIME_GAPS.ja.md)

[文書一覧](README.ja.md)

modern-36 入力における実装、原生根拠、課題です。原 EXE は読み取り専用の静的確認用で、生成工程に不要です。VA は提供された startup_jp.exe に限定し、他版へ適用しません。

## 実装と根拠

- 共通生成は動的 effect・色引数を保持し、レジスター式を0へ変えません。未対応定数はその場で注釈・降格し、動的値は実行時検査。
- キューの effect/tone/tonedep は命令時のレジスターを捕捉し、後読みしません。
- update は共通 `rscript_update_duration` の `codex-ms` を選択し、Forest の百分の一秒を継承しません。Step0=10、溶解Step+1、点陣Step−1、mask2*Step−1、白/黒は各段階Step+1回、Waitはms。`43b390 → 453010 / 4531d0 / 453940 / 452e60` のループが根拠。`update 1 16 16` は2.56秒でなく名目0.272秒。描画費用・Sleep/GetTickCountの追加待ちは模擬せず、固定load/clsやmove速度も精密複製ではありません。
- locgrid は共通座標倍率を実際に更新し、局所変数のみの旧不具合を修正。
- group は所属を記録。cls/move の0はロード済み1〜99、>100は100で割った余りの組。group0は原作同様no-op。全体/組でも各層アニメを実行し、白/黒退出は変換後消去、左右退出は退出転換。
- move5/6は逆向き半円。`413e40` 分岐、`4141b3 / 41421b → 44d3c0` の半周・縦半径が根拠。共通時間・残像を使い、原 frame 精密再現ではありません。
- tboxloc/texloc/namloc は脚本の枠・本文・名前領域。cmploc は画面上のバー位置で、枠右下固定ではありません。
- texsize/texcolor は脚本サイズと数値色表 (`43b6d0`) を共通本文に適用。プレイヤーサイズは相対倍率。
- texloc 幅とユーザー字数で通常行幅を決め、ぶら下がりは保持。
- waitloc/waitlod/waitcol は相対位置・資源番号・色。枠原点に加算し waitNN メタデータを使います。body/grow を先に装入してから継続位置 callback を実行し、ATL が空図で止まる問題を防ぎます。隔離 GL2 は言語・番号切替・黒上の glow を確認。
- texruby のサイズ・字体 slot を共通計測に使用。`46ad7e → 46a1e8` で旧「mode」は字体 slot と確認。`46afa0` は短ルビを本文 span の均等 cell に中央配置、長ルビ全体を中央化し、改行時は残量比例の切上げで再帰分配。`46b125` は本文 cell top から offset を引き、SDK baseline/ascent へ共通変換。サイズ・描画倍率も適用。SDK の行末 advance 改変前に shaped advance を保持し、ink bbox で横 span を推測しません。行間・本文を動かさず、modern 計測のみ有効。旧移植は不可分ルビ・ink位置のまま。未使用の原縦ルビや GDI の pixel 同値は保証しません。
- texmode `42ced0 → 4576c0`、`456c5a` の1=中央、`456ce9` の2=右、他=左。脚本本文矩形内で揃え、^m を上書きしません。原縦書きは別の1b0で、混同しません。
- texpich `42d230` の二引数を17c/180へ。`457086 / 457062` はサイズ+行間／advance+字間。計測と描画を共有し、プレイヤーサイズは比例、行間は原既定からの差分。普通の Ren'Py テキストと旧移植は不変。
- texfont はslotを保存・マッピング。`433e22` はユーザー字体をslot2へ追加し、実呼出も全て2。0/1は原 Inconsolata gt (`45f6e7 / 45f733`、文字列4cd480) で非同梱。未設定はユーザー字体と注釈へ。非零枠は `42a410 / 42a460 / 42aad0` に従い補助三枠も更新。
- cls14 は右下へ移動後に消去。`43a9a0 → 410660 → 411b10` の14番 `411f6a`、終点は初期画布寸法。現0.5秒で、原距離/15のframe調度は未再現。

配置の静的経路は `43b600 / 43b690 / 43b270`（枠/本文/名前）、`43a850`（バー）、`43b870`（サイズ）、`43b840 → 42d0d0`（ルビ）、`43b920 / 43b900 / 43b8d0`（wait）です。

### 拡大転換とオブジェクト

- update100..299 は2026-10-10に実装。`43b390` が百位で `453a60 / 4537e0`、`43ba20` が十位/一位から旧/新画面の九点中心を選びます。`4542c0 / 451b60` の crop は整数 `W*100/(100+level)`、中心を画面内へ clamp。百位1は0..600 step20、各31×5ms=0.310秒、百位2は0..2000 step50、各41×5ms=0.410秒。Step/Waitは無関係。隔離 framebuffer テスト済みですが、GDI sampling・混合は未逐pixel比較。
- mode `43c3b0 → 412b00` は再構築・原表示消去。0は未ロード含む1..99、>100は組。modeを記録し、背景CG・folder・group・depthを保持。Evermaidenのみ有効、mode1/2のnative pixel storage/GDI差は未複製。
- numenable `43bd20 → 41c7c0` は独立数字層を有効化。キュー引数はsnapshot。実脚本はmode0のみ。

### 動的選択

`409750` は答え5以下なら全表示、6以上は一頁4答え+ページボタン。`4090a1` で進み末尾から先頭へ循環。条件で先に絞り、dynnextがボタン文、未設定は4c902cの「次へ」。`43d559` の100答え上限、dynselのclear/appendを保持。`4080f0` の第二引数はsel_qNN/sel_aNNで、共通メタデータ配置を使用。終了・例外時に一時skinを消し、通常選択には影響しません。

selmap がない場合、`408974..408afe` は各skin画布から総高を算出し、各答え前5px、上端 `max(0,H*80//100-total)//2`。各答え中央、タイトルは自身の中央から左30px。空タイトルでも高さを保持。skinなしは共通文字メニュー。普通選択・Forest/Khimeは変更しません。現入力にselmapNNはなく、この原fallbackを使用します。

`43d739..43d762 / 43d81d..43d845` はEffect0（効果有効かつ非Skip）のみ移動、他は原位置。2/3のupdate1/2 15 0は名目待機ゼロで、勝手に時間を追加しません。実2 0 1は原位置のままです。

dyndo Effect0 の動きは `40943b..4096b9`。mode0/1はタイトルから展開、2/3上下、4/5左右、defaultも保持。入場 `44d4c0`、タイトル退出は同曲線、非選択答え退出は `44d310`、選択答えは他が去るまで残ります。量子化cos/sinを再現します。`408de0` の距離/10と `408c1f` の距離/5は速度であり時間ではありません。`44d310/44d4c0` が距離/速度でstepsを決定。`44d880` は `i/256*6.283185308` のQ16表、`44d070` は座標切捨てで、残steps0の次tickに終点へ。

timer は `4eb058+1b4 → 433b99 → 452680`。EXE内WORD既定42msで、共通constructor50msをEvermaidenだけ42msへ。生成物はEXEも元CFGも読みません。実調度はRen'Pyです。頁変更は入場を繰返さず、効果off/Skip時は動かず、動作中入力を止めます。同じmetadata部品を使用し、余分なcheckpointを作らず回帰forwardデータを上書きしません。速度除数未満の極短移動は直接終点へ落とし、原ゼロ速度分岐の開始点停止を避けます。現通常skinにこの境界はなく、現れたら再比較が必要です。

## 未完成

- makesave `43e310 → 433140` は0x996c bytesと局所レジスター7000個をメモリーへコピーし、ファイルを書きません。renpy.save相当でなく、「現在位置でなく以前snapshotを保存」の意味は未再現。数字の他命令、他命令の組選択も未逐項確認。
- 固定字体slot0/1の字形、原縦ルビは未再現。
- 外部selmap読取なし。mode0はその起終点を使うべきですが、現実装はファイルなしfallbackのみ。LWG metadataとは別形式です。
- 未知の動的効果は実行時に明確なエラーになる場合があり、静的ゼロ化撤去は全効果対応を意味しません。
