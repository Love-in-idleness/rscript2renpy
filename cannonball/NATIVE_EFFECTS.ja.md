画像効果、時刻、VM、クリックの根拠です。読み取り専用の `Cannonball.exe`、SHA-256 `df4b5b6dffc7002370d0772869baaba551b08fca970e92609ca64b08174f89ba` を対象とし、EXE は実行せず、生成にも不要です。以下はこの PE の VA です。

| 引数 | 静的経路と意味 | 移植 |
| --- | --- | --- |
| BGM fade | `4181b0/4181f0 → 42c6f0/42c790 → 43a510/43a570` 非零スイッチ。`43d122` は20ms、`43db4f/43dba6` の100 steps=2000ms | switch と原値注釈を保持、共通二channel crossfade |
| load/cls9 | `40371a/4041b2 → 425690` y=負の画像高 | 上から入る／上へ出る |
| load/cls17 | `403aa1/4044a2 → 425d30` mode20、step16。`41df89 → 420320` は `(y&15)>(level>>4)` かつ `((x+y)&15)>(level>>4)` | 格子 wipe shader、alpha/深度保持 |
| draw3等（1/2以外） | `405490`: 1→mode2、2→mode14、他→mode0 | draw3 は新版 Grade 混合を使い、他の別名は原義を保持 |

draw `405490 → 41cc90/41cd60` は再 load 不要で表示を即更新。動的混合状態を load、move、hide/restore、hover代替に適用し、位置・アニメをリセットせず、キュー順を保持します。SDK framebuffer で通常・透明・加算・キュー前後を確認。共通 shader の百分率精度であり、原整数 pixel 完全一致とはしません。

## 文字の訂正と ^g

CannonBall 生成器で完全一致の文のみ訂正し、原版・パッチ資源は変えません。6101のvoice19604は日文 ^n に対し中文裸 ^g の改行誤記。2402 voice446/448 の中文 ^g63 は合法で、日文 ^g63150/^g6340 は名前番号と本文数字の連読を避けるため正確に `^g063^cw150 / ^g063^cw40` へ訂正します。数字の境界を一般推測しません。各訂正を生成注釈へ残します。中国語2108の _oload44 171 95 0 0 の「１１３０」は生成時に「１１３０（正确）」とし、他言語・他選択肢は不変です。

`426d1b/426d4e` は G/g を `426f18` へ、`426f6c` は整数 reader `42eaa0` へ渡し、終了ポインターを本文へ戻します。`42eaa9..42eab8` は空白・tab、`42eab8..42eac3` は負号、`42eac3..42ead9` は全 ASCII 数字を value*10+digit で読むため三桁制限なし。`427520/42752a` で低16bit、`42753b..427541` は `%s%03d`（文字列4500b0）で資源名化。039/0039/39は同義。^aも同 reader ですが、その Wiki 意味はこの訂正範囲外。静的根拠であり EXE は未実行です。

## 退出と数字

cls31 `404900 → 4260e0/42fd00` は左右二分し、右を上、左を下へ150px。`4255e0/425740` の四分の一正弦、`425d30` の fade、50ms×16=0.8秒。両版5204で使用。

cls34 `404b22 → 4247a0/424db0` の12は step。level254から12ずつ減らし、`42f740` で回転・level*100//256%縮小、`425aa0/425b10` で振幅250px、20step正弦上下、22frames=1.1秒。原1602の二箇所。共通実装は位置・anchor・depthを保持し、破片の原境界外退出とクリック後清理に対応。Ren'Py 回転 sampling、奇数幅の1pxは原作との差が残ります。

数字は `4178b0 → 408a40` で Num/Bar/Fix。`42d0b0 → 428160/4283a0` は Num を縦10frame、八桁右寄せ、先頭ゼロ非表示。`42d450` は残差の1/5をゼロ方向切捨て、最低1。`42b800/42b920` は50ms。`408ce0/415c40` は Animate非零で待ち、0は即完了。欠けた skin は代替文字なし、skipで終値。実脚本はBarのみなのでNumは合成fixtureで検査し、実ゲーム素材の存在とはしません。numreng Mode/Digitsは `408d60` に保存されますが描画経路は消費せず、意味を推測しません。

目視入口: title0002 load9、中文5703/7505 cls17、5204 cls31、原1602 cls34/HP bar、6502即draw。BGM変更の同時 crossfade、同曲の非再起動も確認します。

## 尾巴ミニゲームの音声

`415097..4150b5` は voice 四引数を `415c10` へ。高16bit=間接回数、低16bit=符号付きレジスター。9020 の `0x00011839..0x0001184a` は `@6201..@6218` で、9040 が表を設定します。旧出力は rscript18 を誤選択し literal71737..71754でした。LiarsoftTool の配置採点を修正したため再出力が必要で、生成器は旧過大 literal を拒否し音声名を推測しません。`418140` の Repeat999 はloop、9003のクリック後は voice_off で停止。有限Repeat>1、Fade/Panは未完成です。同種2..7枚の取得時 voice とクリック後停止を目視・試聴してください。

コンパイルは全日中脚本と式、隔離SDKは音声API（試聴なし）、GL2は格子・分割・回転・混合・清理を検査します。lint とテストは原速度、音量曲線、全ルート、Androidを証明しません。
