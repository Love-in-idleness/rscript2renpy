# Локальные пути

[中文](LOCAL_WORKFLOW.zh.md) | [English](LOCAL_WORKFLOW.en.md) | [Русский](LOCAL_WORKFLOW.ru.md)

`local.paths.toml` хранит пути инструментов, ресурсов и результатов на вашей
машине. Это необязательная конфигурация: она не передаёт параметры генераторам
и не включает патчи автоматически.

## Настройка

Скопируйте `local.paths.example.toml` из корня в `local.paths.toml` и замените
примеры своими абсолютными путями.

| Раздел | Содержимое |
| --- | --- |
| `tools` | Два репозитория, CLI/GUI LiarsoftTool, каталог сборки и Ren'Py SDK |
| Игра | Преобразованные ресурсы, выходной проект и базовый язык |
| `patches` игры | Метки языков и каталоги патчей |

Неиспользуемые поля оставьте пустыми. Файл игнорируется Git: не коммитьте личные
пути. Без него можно просто передавать пути генератору напрямую.

## Правила работы

- Оригиналы игры и патчей доступны только для чтения; преобразования выполняются на копиях.
- Выходной проект находится вне ресурсов.
- Перед повторной сборкой сохраняются ручные изменения проекта.
- `rebuild_local.sh` — локальный вспомогательный скрипт, не точка входа для других пользователей.

Два репозитория могут использовать один файл, чтобы не дублировать пути.
Открывайте инструментам только каталоги, нужные текущей задаче.
